## M03｜从 Attention 到完整语言模型

### L021｜FFN 与非线性为什么存在
**前置：** L002、L010、L016；知道输入表示与可学习参数的区别。
**问题与目标：** Attention 负责信息交互，但一个 block 还需要怎样变换每个位置的特征。
**教学顺序：** 连续线性变换可合并→加入非线性的表达差异→逐 token FFN 的升维/非线性/降维；ReLU、GELU、门控结构按解释深度比较，不同时实现所有变体。
**练习与产物：** 实现两层 FFN；打印 [B,T,D] 的变化；对不带非线性版本做合并矩阵对照，再加入非线性观察反例。
**独立验收：** 解释 FFN 为何不等同于另一次跨 token attention；说明维度恢复不等于变换没有作用。
**错误与回补：** 不把非线性当作“为了随机”。线性合并不清回 L002，训练路径不清回 L015；下一课处理深层堆叠。

### L022｜Residual、Normalization 与训练状态
**前置：** L021、L014–L017。
**问题与目标：** 解释完整 block 中的相加、归一化和训练/推理模式，而不只背结构图。
**教学顺序：** x+F(x) 的两条路径→相加的 shape 约束→LayerNorm 的归一化轴→RMSNorm 对照→Pre-LN/Post-LN→dropout 的训练与推理差别。先学机制，不要求证明所有稳定性结论。
**练习与产物：** 实现一种 norm 与 residual block，对照基础库结果；比较 train/eval 模式及不同 batch 的影响，记录归一化的轴。
**独立验收：** 解释 residual 不是“自动保留一切信息”；区分 eval 模式、no_grad 与参数冻结。
**错误与回补：** 不把 LayerNorm 当作 BatchNorm。轴问题回 L004，梯度分路回 L014；下一课比较模型家族。

### L023｜Encoder、Decoder、Cross-Attention 与 Mask
**前置：** L008、L010、L022。
**问题与目标：** 看懂“Transformer”不是只有一种拓扑，架构要服务任务的信息可见性。
**教学顺序：** encoder-only 的双向表示→decoder-only 的因果预测→encoder-decoder 的输入/输出分离→cross-attention 中 Q 与 K/V 的来源→causal/padding mask。
**练习与产物：** 为分类、生成、翻译三个任务画信息流；手推长度不同的 cross-attention shape；写一个未来可见性测试。
**独立验收：** 回答“decoder 的每种 attention 都必须只看左侧吗”，明确 self/cross 的区别与任务条件。
**错误与回补：** 不把 encoder/decoder 名称当作安全可见性保证。混淆回 L007–008；下一课定义语言建模输出。

### L024｜LM Head、Logits 与 Next-Token Labels
**前置：** L005、L018、L023。
**问题与目标：** 把隐藏表示与词表预测、监督目标接起来。
**教学顺序：** hidden [B,T,D]→LM head→logits [B,T,Vocab]→目标 token→label shift→有效位置的 Loss；再说明训练多位置并行与生成逐步进行的区别。
**练习与产物：** 手写一条短序列的输入/目标对齐表；实现 toy LM head 和 label shift；对 padding/ignore 项测试；记录 weight tying 是否使用。
**独立验收：** 区分 d_model、head width、vocab size；解释“输出矩阵 T×Vocab 中每一行预测的究竟是谁”。
**错误与回补：** 不直接把当前 token 当未经移位处理的目标；不要给接收 logits 的损失重复做不必要 softmax。混淆回 L018。

### L025｜语言模型数据与可复现实验
**前置：** L018、L024。
**问题与目标：** 模型代码正确也可能因数据重复、目标错位或划分泄漏得到虚假结果。
**教学顺序：** 语料来源/授权→清洗与去重→按文档划分→tokenization→block/边界处理→batch；记录数据版本、词表版本、seed 与 split。
**练习与产物：** 建一个小语料 manifest 与 loader，检查跨集合重复和 document boundary；输出两批可人工检查的输入/labels/mask。训练数据与评估题不要混用。
**独立验收：** 说明为什么不能先把同一文档随意切碎再随机分训练/测试；用样本检查而非只看 shape 验证 label。
**错误与回补：** 数据划分依据任务而定，避免用一个随机切分法替代所有场景。目标不清回 L024；下一课组装 P1。

### L026｜微型 Decoder LM：先把 Forward 接通
**前置：** L010、L021–L025；L020 训练模块达到门槛。
**问题与目标：** 形成可以逐层解释、而不是一行调用黑盒的模型。
**教学顺序：** embedding/位置→1–2 个 block→final norm→LM head→Loss；先以小配置验证全链，明确每层职责与参数 shape。
**练习与产物：** 完成可配置 P1 forward，加入每层 shape 断言、causal/padding 测试、有限数检查；不直接用完整 Transformer 类代替核心学习代码。基础张量/autograd 可以复用。
**独立验收：** 不看实现画出模块与轴变化；面对换长度/换 head 数的配置，指出合法约束和需要改动的位置。
**错误与回补：** 运行不报错不等于信息流正确。错误定位回到具体层；下一课正式训练与恢复。

### L027｜完整训练、验证、Checkpoint 与生成
**前置：** L016–L018、L025–L026。
**问题与目标：** 建立 P1 从数据到参数更新再到使用的真实闭环。
**教学顺序：** 小样本 sanity check→batch forward/Loss/backward/step→独立验证→保存/恢复参数与优化器→生成；固定预算，不以无休止加训练步数掩盖 bug。
**练习与产物：** 保存配置、Loss 记录、梯度检查、checkpoint、恢复日志与生成样例。先证明在小训练集上能学习，同时明确过拟合与泛化不是同一个验收。
**独立验收：** 区分训练结束、验证选模和生成；解释哪些状态影响继续训练的一致性。
**错误与回补：** Loss 异常先查 labels/mask/数值/梯度，不默认模型太小。回补 L020 的定位方法；下一课独立验收。

### L028｜P1 验收：实现、因果与排错
**前置：** L021–L027。
**问题与目标：** 证明能解释并验证完整 Transformer，而不只是单层 Attention。
**练习与产物：** 用新配置跑训练/恢复/生成；教练隐藏一个 label 或 mask 错误，学习者定位；保存测试命令、日志、失败案例与 P1 README。
**独立验收：** 从 token ID 一直讲到 Loss 与联合更新；改变未来 token 不应影响其之前的因果预测；说明 tiny LM 的结果不能代表通用大模型质量。
**四维门槛：** 概念职责清楚；全链 shape 与梯度解释正确；代码和异常路径有证据；无提示应对一个更换任务/架构的追问。
**回补与复习：** 失败返回具体学习日，已通过模块保留；下一章进入使用模型的推理、成本与选型。

## M04｜推理、性能与模型适配

### L029｜调用模型、Prompt 与结构化输出
**前置：** L024、L028；后端接口经验。
**问题与目标：** 从“模型结构”转到“应用怎样提出任务并验证结果”。
**教学顺序：** 训练更新参数 vs 推理读取参数→messages/角色→明确目标、约束、示例→结构化响应 schema→解析和业务校验→失败路径。接口语义以所选 provider 的官方文档为准。
**练习与产物：** 为一个分类/字段抽取任务建立固定小样本与 expected output；用 fake provider 测协议异常，再用已获授权的模型测试质量，记录两种证据不能互换。
**独立验收：** 解释“输出合法 JSON”为什么仍可能业务错误；说明 system 指令不是替代服务器权限的安全边界。
**错误与回补：** 不靠追加长 prompt 掩盖错误数据或模糊目标。输出层理解不清回 L024；下一课研究采样。

### L030｜采样、停止条件与可复现性
**前置：** L003、L024、L029。
**问题与目标：** 区分概率分布、解码策略与模型能力。
**教学顺序：** greedy→temperature→Top-K/Top-P→stop/max tokens→多次试验；解释采样随机性和实现中的其他非确定性。
**练习与产物：** 对一个固定 logits 向量比较解码配置；给 P1 生成加入采样与终止；保存配置、重复输出和长度，不从单次好例推断提升。
**独立验收：** 说明 temperature 改变的是什么；低 temperature 为什么不构成事实正确性保证。
**错误与回补：** 不把选取 Top-K 与 attention softmax 混为一谈。概率不稳回 L003；下一课研究重复计算。

### L031｜Prefill、Decode 与 KV Cache
**前置：** L007、L023–L024、L030。
**问题与目标：** 解释生成逐步进行时哪些历史计算可以复用。
**教学顺序：** 初始 prompt prefill→逐 token decode→每层历史 K/V→cache 读写与 position/mask 对齐→TTFT 与每 token 延迟；不将 cache 说成保存模型知识的长期 memory。
**练习与产物：** 在小模型上比较带/不带 cache 的 logits，在预定数值容差内一致；记录不同序列长度的时间与 cache 估算，CPU 结果不外推为 GPU benchmark。
**独立验收：** 解释缓存哪些量、为什么不是简单缓存一次最终回答；区分 KV cache、响应缓存和 prompt 缓存。
**错误与回补：** cache off-by-one 回 L024，层/轴错误回 L004；下一课看工程变体。

### L032｜现代 Attention 与推理资源账本
**前置：** L009、L022、L031。
**问题与目标：** 看懂 RoPE、MHA/MQA/GQA、量化和 FlashAttention 的收益分别作用于哪里。
**教学顺序：** 位置表示与 Q/K 旋转的关系→Q 头与 K/V 头数区别→cache/权重/临时激活的内存构成→精度与数据搬运→kernel 优化。以机制/算账为主，不手写 GPU kernel。
**练习与产物：** 对给定层数、KV heads、head width、token 数和 dtype 估算 cache 内存；改变一个参数做对照；给出优化是否影响模型表示/数值/执行方式的分类表。
**独立验收：** 说明减少 KV heads 主要改变什么；不把 FlashAttention 当作所有情况下消除了 attention 的平方算术复杂度。
**错误与回补：** 不用“更快更省”替代明确条件。版本/实现细节上课前查官方文档；与用户设备不匹配的性能结论标未验证。

### L033｜Pretraining、SFT、LoRA 与偏好优化
**前置：** L018–L020、L024、L029。
**问题与目标：** 判断何时修改参数，区分训练目标、数据和可训练参数范围。
**教学顺序：** pretraining→SFT 样本与目标→PEFT/LoRA 的低秩增量→冻结/更新参数→偏好数据、RLHF/DPO 的目标差异；只要求必要数学，不把完整强化学习推导塞进本日。
**练习与产物：** 在小型线性层实现低秩增量，核对冻结参数与可训练参数数量；为一个任务写数据、对照、验证与停止条件方案。完整大模型微调运行属于资源允许后的扩展，不预先算通过。
**独立验收：** 区分 LoRA 方法与 SFT 目标；说明微调为何不能自动成为可靠实时知识库。
**错误与回补：** 不把所有后训练都叫梯度下降一章的同一种任务。梯度边界不稳回 L019；下一课做应用选型。

### L034｜Prompt、RAG、微调与部署选型门槛
**前置：** L029–L033；RAG 此时只需理解检索外部证据的基本接口，细节在下一章正式学习。
**问题与目标：** 将模型基础用于质量、延迟、成本、更新频率和隐私的取舍。
**教学顺序：** 明确失败类型→列候选→设共同评估集→比较证据需求/行为适配/模型能力→记录约束与 ADR。不能因名词更先进就选择更复杂方案。
**练习与产物：** 对“输出格式不稳、每天变的知识、工具副作用错误”三个场景分别写首选干预、对照实验和回退条件；为授权可用的推理环境记录模型/配置/版本/成本项。
**独立验收：** 解释哪些问题不是靠训练能解决；给出一个推翻自己首选方案的观察结果。
**回补与衔接：** 不能区分训练/推理回 L029；不能区分适配范围回 L033；通过后进入可评测 RAG，而不是直接绑定一个框架。
