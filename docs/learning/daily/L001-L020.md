## 使用方法与统一标准

L 编号不替换历史 Day。已有学习证据先迁移，仅补未通过的前置；单张卡可以分成多个会话。每天先复习到期项，再按“问题→解释→算例→独立练习→追问→纠错”推进。每张卡的前置是入场条件，不是默认已掌握。

每天的产物是待完成任务，保存在学习记录/实验目录，不在本计划中预写结果。Concept 验收是解释动机；Mechanism 是完成当天推导；Engineering 是提交并检验产物；Interview 是不看笔记回答卡中的问题。需三者以上有证据，其中机制和独立解释不可缺；当天未涉及工程实现则标不适用，不伪造分数。

最低通过之后再安排延迟复测。失败只回补卡中前置或指定步骤；不要整章机械重讲。每个模块末都有综合门槛。公式教学时逐个解释符号，不一次展示验收题答案。

## M00｜数学、张量与实现桥梁

### L001｜轴与张量：先建立共同语言
**前置：** 后端编程经验；Python 熟练度、开发设备尚待诊断，不要求已会 PyTorch。
**问题与目标：** shape 相同不代表含义相同；要能指出 batch、token、feature 分别是哪条轴。
**教学顺序：** 从一条三维记录到多条记录，再到多条序列；区分数值、索引与模型参数；最后介绍最小 Python 张量表示，不讲梯度。
**练习与产物：** 给两条长度为 3、每个 token 有 4 个特征的序列标轴；写读取、切片、求和与 shape 断言，并故意制造轴用错的反例。记录设备与可用工具，不假设 GPU。
**独立验收：** 换成未见过的 batch/长度后仍能解释；回答“沿 token 轴与沿 feature 轴求和，分别丢掉了什么？”
**错误与回补：** 把 512 维当作 512 个 token 时，回到单条记录；代码语法不足只补语法。下一课使用这些轴做矩阵乘法。

### L002｜线性映射不是切片或分组压缩
**前置：** L001 的向量与轴。
**问题与目标：** 把 Projection 从术语还原为可手算的加权组合。
**教学顺序：** 点积→行乘列→矩阵乘法→转置；解释 y_j=Σ_i x_i W_ij。每个输出可使用全部输入，系数可正可负，不要求归一化。
**练习与产物：** 自己完成 3→2 和 2→4 两个映射；再构造两个不同输入经同一降维矩阵得到相同输出，保存手算与代码对照。
**独立验收：** 不用 512/8 原例推导 XW 的维度；解释“投影后使用了所有输入，为什么仍不保证无损？”
**错误与回补：** 不用卷积核大小推出固定压缩比。混淆时逐项展开一个输出；下一课学习分数如何成为概率。

### L003｜概率、log/exp 与 Softmax 的轴
**前置：** L001–L002；不预设概率课程基础。
**问题与目标：** 分清任意分数与概率分布，为 attention 和 Loss 两条线准备基础。
**教学顺序：** 非负与总和→条件概率→exp/log 直觉→Softmax；区分对行与对列归一化；均值、方差只做到解释数值波动，导数留给 M02。
**练习与产物：** 将两行不同 scores 各自归一化；给全部 scores 加同一常数并比较结果；以减去最大值的形式实现数值稳定计算。
**独立验收：** 说明 Softmax 不是 Top-K；回答“每行和为 1 与整个矩阵总和为 1 是同一个要求吗？”
**错误与回补：** 不把 softmax 输出直接当可信度校准结果。若 log/exp 不稳，先做小数表，不推进交叉熵。

### L004｜批量 shape、广播和实现入场门槛
**前置：** L001–L003。
**问题与目标：** 把一个 token 的计算推广到一批序列，同时避免隐式广播掩盖错误。
**教学顺序：** X[B,T,D] 乘 W[D,F]→矩阵批处理→reshape 与 transpose 的区别→dtype、浮点误差与近似比较。
**练习与产物：** 用编号张量跟踪 reshape/transpose 后每个数的位置；测试多个 B/T/D/F；形成基础 shape 测试文件。
**独立验收：** 从新配置推导输出轴，并找出一个“shape 合法但语义错”的操作；不用整层 Transformer API 代替检查。
**错误与回补：** 一个三乘二题通过不代表本章通过。门槛失败定位到轴、乘法或代码；通过后进入 Token/Attention，已学部分走验证通道。

## M01｜Token、表示与 Attention

### L005｜从文本到 Token Embedding
**前置：** L002、L004；训练如何发生暂不要求。
**问题与目标：** 区分文本、token ID、embedding lookup、contextual representation 和检索 embedding。
**教学顺序：** 子词/字节分词动机→小词表与 ID→embedding 表按行读取→上下文层更新表示；同一词的分词受 tokenizer 规则影响，不假设一字一 token。
**练习与产物：** 为一段中文、英文与代码样例列出 token/ID；用教学词表做 lookup，标出 vocabulary size 与 d_model 的区别。真实 tokenizer 实验记录名称与版本。
**独立验收：** 解释“ID 的数值更大是否代表语义更强”“聊天模型内部 embedding 能否直接当检索 embedding 用”。
**错误与回补：** 不默认 embedding 每维限制在 -1 到 1。混淆词表轴与特征轴时回 L001；下一课连接信息交互。

### L006｜RNN 到 Q/K/V：以新例验证已有学习
**前置：** L003、L005；读取历史 Day 1–3 的已有证据。
**问题与目标：** 保留已学内容，只检查信息路径与 Q/K/V 的因果解释。
**教学顺序：** 用新序列比较递归状态与直接交互；从“当前需要什么、怎样匹配、传递什么”解释 Q/K/V；指出这些是帮助理解的角色类比，不是参数的固定自然语言语义。
**练习与产物：** 手算两个 Query 对三个 Key 的分数，分别加权 Value；仅在有混淆处补课。
**独立验收：** 解释同一个 Key 对不同 Query 为什么权重不同；指出 RNN 不需要额外读取一个显式位置编号才能递归。
**错误与回补：** 不把 Value 当最终概率或把注意力权重当 token 的永久重要性。通过后做完整数值实现。

### L007｜Scaled Dot-Product Attention 的完整计算
**前置：** L002–L006。
**问题与目标：** 能从 Q/K/V 独立推导 score、weight 与输出，区分 T×T 和 T×d_v。
**教学顺序：** QKᵀ→除以 √d_k→沿 Key 轴 Softmax→乘 V；scaling 的统计直觉必须说明假设，不将其描述成所有输入下的严格尺度保证。
**练习与产物：** 写基础张量版 attention；固定小矩阵与手算对照；测试行和、输出 shape 与改变 V 不改变当前分数矩阵。暂不使用内置完整 attention 替代实现。
**独立验收：** 更换 token 数、d_k、d_v 推导 shape；解释输出为什么不是“新的 Q”。
**错误与回补：** Softmax 轴错误回 L003，转置错误回 L002；下一课加入 mask 与位置信息。

### L008｜位置、Mask 与可见性
**前置：** L005–L007；历史 PE 学习只作已有接触证据。
**问题与目标：** 区分位置表示与允许看哪些 token，修正“ABC/CBA 原位输出完全相同”的过度简化。
**教学顺序：** 不带顺序信号的 self-attention 重排关系→固定/可学习 PE→不同频率的 sin/cos→causal 与 padding mask。相位与位移说明条件，不承诺任意长度的唯一解码或可靠外推。
**练习与产物：** 做输入重排对照；加入 causal mask 后改变未来 token，检验前面可见位置不受其影响；测试 padding。实现必须单独处理全被遮挡的异常输入。
**独立验收：** 用新句子区分“输出随着输入重排”和“输出原位不变”；解释 mask 与 PE 不能简单互相替代。
**错误与回补：** 不再连续问同一个 ABC/CBA 题。数学缺口按 L003 回补；下一课进入多头投影。

### L009｜多头：相同输入，不同可学习映射
**前置：** L002、L004、L007。
**问题与目标：** 分清读取完整输入、投影后拆 head 轴和直接切原 embedding。
**教学顺序：** 每头各自 W_Q/W_K/W_V→低维 Q/K/V→各头 attention pattern；再对照合并线性层后 reshape 的等价实现。
**练习与产物：** 使用 d_model=12、3 heads 推导并实现；对照循环版本与向量化版本输出；计算标准配置的参数规模，不把 head 数增长一律说成免费。
**独立验收：** 解释“两个头同为 64 维，为何仍可能不同”“所有投影和输入完全相同时会怎样”。
**错误与回补：** 不保证各头必然学出不同语义职责；512→64 是设计选择而非数学定律。回 L002 可补映射理解；下一课合并输出。

### L010｜Concat、W_O 与 MHA 全链验收
**前置：** L009。
**问题与目标：** 解释 feature 级线性混合，完成从 X 到多头输出的闭环。
**教学顺序：** 各头 T×d_v→Concat 得 T×(h d_v)→W_O[(h d_v),d_model]；原 8×64 案例恰好拼回 512，但一般配置仍可能需要维度映射。
**练习与产物：** 实现输出投影；测试拼接顺序、W_O shape、换配置、identity W_O 对照；提交 MHA 测试和无提示说明。
**独立验收：** 从未见过的配置完整推导，并解释 W_O 不是每个 head 一个概率权重、也不更新别的位置的 token 表示。
**错误与回补：** 不把“融合”当作已经讲清数学。未通过定位到 L007/L009/本课，不立即重复整章；通过后正式进入训练机制。

## M02｜神经网络如何学习：十个学习日

本模块对齐 ../modules/M02-training-mechanisms.md 的 T01–T08：L011=T01，L012=T02，L013–014=T03，L015=T04，L016–017=T05，L018=T06，L019=T07，L020=T08。拆分是提前规划，不是临时插课。

### L011｜训练样本、目标、参数与 Loss
**前置：** L002–L005；不要求导数。
**问题与目标：** 先定义什么算错，再讨论参数如何变化。
**教学顺序：** 数据 x 与目标 t→ŷ=wx+b→平方误差→参数/超参数→训练、验证用途；“预测改变”与“参数更新”分开。
**练习与产物：** 用同一批小样本比较两组参数，填写预测、目标、Loss 表；修改目标再比较。准备数据来源和划分说明。
**独立验收：** 说明训练究竟改变了什么；为什么一次输入输出不代表已经训练完成。
**错误与回补：** Loss 本身不直接指定某个参数加多少。区分不清回到数据/参数表；下一课研究局部变化方向。

### L012｜导数、梯度与有限差分
**前置：** L011；函数与平方运算。
**问题与目标：** 理解梯度是局部变化率，不是神秘的错误责任分数。
**教学顺序：** 两次近邻试算→中心有限差分→导数→多参数梯度→学习率；推导一个平方误差模型的一次 SGD 更新。
**练习与产物：** 手算新数值例，写有限差分对照；比较小步长、零步长、过大步长的更新后 Loss。
**独立验收：** 解释正梯度为什么用减法更新；给出步长过大时 Loss 反而上升的证据。
**错误与回补：** 不把每一步下降、验证集提升或全局最优当保证。斜率不稳先用数表，不进入链式法则。

### L013｜链式法则：跨过两层计算
**前置：** L012。
**问题与目标：** 最终 Loss 为什么能影响靠近输入的参数。
**教学顺序：** u=ax、y=bu、L→各段局部导数→沿路径相乘；逐项解释变量和中间量，不直接塞入 Transformer 大图。
**练习与产物：** 自画计算图，独立算 a、b 的梯度和一次联合更新，再与有限差分比较。
**独立验收：** 解释一个标量 Loss 怎样对应多个参数的梯度；所有梯度必须来自同一次前向的参数快照。
**错误与回补：** 不先更新 b 再无说明地用新 b 计算旧图的梯度。未通回 L012；下一课处理多路径。

### L014｜分叉计算图与反向传播
**前置：** L013。
**问题与目标：** 一个输入影响多条路径时，学习信号如何合并。
**教学顺序：** 一条路径到分叉/汇合→局部导数乘法→多路径相加→反向顺序→缓存前向中间量；反传是高效求导，不是试遍所有参数。
**练习与产物：** 对 y=ax+bx 和一个共享中间量的网络手算梯度；设计漏掉一条路径的错误实现并定位。
**独立验收：** 不用“自动算的”作答，解释共享参数为何收到多路梯度；区分 backward 与更新参数。
**错误与回补：** 误把多路贡献取平均时回画图，聚合方式必须来自定义的 Loss；下一课推广到矩阵。

### L015｜Projection 的矩阵梯度
**前置：** L002、L004、L014。
**问题与目标：** 从标量参数真正走到 W_Q/W_K/W_V/W_O 这样的矩阵。
**教学顺序：** Y=XW；给上游 G=dL/dY，先推一个元素，再得到 dL/dW=XᵀG、dL/dX=GWᵀ；说明 batch/token 使用同一 W 时的梯度聚合。
**练习与产物：** 对小矩阵逐元素计算，用 float64 有限差分核验，预先写清容差和误差来源；检查每个梯度 shape。
**独立验收：** 不仅背公式，还要说明一个权重连接了哪些输入与输出、梯度怎样依赖上游 G。
**错误与回补：** 转置错回 L002，链路错回 L014；下一课用 autograd 实现闭环。

### L016｜Autograd 与最小训练循环
**前置：** L011–L015；基础 Python。
**问题与目标：** 看到预测、Loss、backward、optimizer 各自改变了什么。
**教学顺序：** requires_grad 与计算图→forward→Loss→backward→SGD step→下一批；分别检查参数、梯度、优化器状态。
**练习与产物：** 写小网络训练脚本，打印更新前后参数与梯度；加入 detach、冻结参数、漏清梯度三个对照中的至少两个。禁止用高层 Trainer 隐藏核心步骤。
**独立验收：** 说明为何调用 backward 不等于参数已经更新；解释冻结与不参与计算路径两种情况。
**错误与回补：** 不把所有参数每步都有非零梯度当规则。手算对照失败回 L015；下一课解释训练调度与优化器。

### L017｜Batch、Step、学习率与优化器
**前置：** L016。
**问题与目标：** 分清训练组织方式与参数更新算法，避免只记 API。
**教学顺序：** batch/step/epoch→梯度累积→SGD/Momentum→Adam/AdamW 的状态与动机→学习率与权重衰减的区别。手算限于 SGD，其他优化器以机制和实验为主。
**练习与产物：** 对同一小任务比较两种学习率；写出 batch size 和累积步数的配置；保存参数与优化器状态并恢复一步训练。
**独立验收：** 解释恢复训练为什么可能不能只加载权重；清梯度操作如何随累积边界变化。
**错误与回补：** 不宣称某优化器总是最好；NaN 或不学习先定位数据、梯度、步长。下一课连接分类目标与泛化。

### L018｜交叉熵、数据划分与泛化
**前置：** L003、L011、L016。
**问题与目标：** 知道语言模型最终从哪里获得监督，而不是把任意 softmax 都当同一个东西。
**教学顺序：** logits→类别概率→目标类别→负对数似然→训练/验证/测试；解释 attention 归一化轴与类别轴的不同。具体损失 API 是否接 logits 以官方说明核验。
**练习与产物：** 比较两个预测分布对同一目标的 Loss；对小分类器保存训练/验证趋势；制造重复样本跨集合的泄漏并解释风险。
**独立验收：** 说明低训练误差为何不代表泛化；如何避免把同一验证集反复调成事实上的训练集。
**错误与回补：** 不把 Loss 改善等同于业务全面改善。概率不稳回 L003；下一课回到提出问题的 Transformer。

### L019｜Head 与 W_O 的联合训练
**前置：** L010、L015–L018。
**问题与目标：** 完整回答“先训练 Head 还是 W_O；一个 Loss 怎么影响全部矩阵”。
**教学顺序：** 教学 Loss→输出层→W_O→Concat 梯度分流→各 Head→V 与权重路径→Softmax/QKᵀ→各投影；再区分全参数、冻结与分阶段设置。
**练习与产物：** 对小型多头层接一个明确的教学目标，记录所有投影的梯度 shape 和更新；固定数据比较冻结 W_O、断开路径与正常训练。此目标不冒充真实语言建模任务。
**独立验收：** 沿图解释学习信号，不停在“它可训练”；区分一次可联合更新和一次就训练完成。
**错误与回补：** 不宣称全部模型永远一次共同训练。缺口回对应算子/梯度日；下一课独立调试。

### L020｜训练机制综合验收与故障定位
**前置：** L011–L019。
**问题与目标：** 证明不仅听懂，还能在新例和错误程序里使用训练心智模型。
**练习与产物：** 教练从错误目标、过大学习率、detach、意外梯度累积、数据泄漏中隐藏至少两种故障。学习者先提出诊断顺序，再用证据修复，提交一份失效分析与最小训练脚本。
