## 每日共用执行契约

每张卡的“目标”说明当天定位；“前置”是开课前检查项，不足时先走回补；“讲解链”按动机、心智模型、机制、必要数学展开；“练习/交付”必须由学习者动手；“验收/追问”在讲解后换数值或情境、无提示进行。先教学再验收，不用连续猜测代替讲解。

四维验收分别记录 Concept（解释问题）、Mechanism（推导机制）、Engineering（完成练习与排错）、Interview（独立表达与边界）；尚未检查的维度写“待验证”。一题答对不等于整章掌握。常规单元排程假设为 60–90 分钟，代码实验可拆为多次会话；这不是用户已确认的可用时间。

每日实际结果初始均为“未按新卡验收”；历史证据由状态文件迁移。每次结束写日期、实际完成、原始回答摘要、提示程度、错误与修正、产物路径、四维状态、下一入口。复习默认先登记下一次会话的错点检查，再按实际证据使用项目的约 3/7/30 天间隔；没有有效评分不伪造分数。章节门槛日也是回补缓冲，未过只补失败依赖，不机械重学全章。

## M00：数学、张量与实现桥梁（D001–D006）

### D001｜起点校准与可复现实验环境
**前置/目标：** 使用已有 2026-09-28 Baseline，不重做全套测试；确认尚未验证的 Python/PyTorch、张量读写和实验条件。
**讲解链：** 为什么可运行不等于可复现 → 输入/配置/环境/结果的边界 → 建立 P1/P2/P3 的证据目录。先让学习者读一小段现有代码，再补必要语法，不假定后端年限等于 PyTorch 熟练度。
**练习/交付：** 运行一个本地张量脚本，记录 Python、框架版本、设备与随机种子；建立实验日志和依赖锁定文件。默认 CPU 与 mock；未经确认不使用付费 GPU/API，也不上传真实私有数据。
**验收/追问：** 能自行重跑并解释输入、参数、输出各在哪里；更换随机种子后哪些结果应或不应改变？
**回补/衔接：** 环境问题只补环境，语法问题只补相应代码；随后 D002。工程映射：把后端的可重现故障定位迁移到 AI 实验。

### D002｜向量、矩阵与 batch/sequence/feature 轴
**前置/目标：** D001；能区分样本数、token 数和每个 token 的特征维度。
**讲解链：** 一个数 → 一个 token 向量 → 一个序列矩阵 → 一批序列张量；每条轴有自己的语义。shape 相同不代表语义相同，位置序号也不是 feature 下标。
**练习/交付：** 为 B=2、N=5、D=6 的输入逐轴标注；分别索引第一个样本、第三个 token、第四个 feature，并写 shape 断言。
**验收/追问：** 不看例子推导另一组 B/N/D；增加 token 数和增加 embedding 维度分别改变哪一轴？
**回补/衔接：** 混淆轴则回到一张 token×feature 数表；随后 D003。产物：带轴语义的张量说明，不只是一串尺寸。

### D003｜点积、矩阵乘法与 Linear Projection
**前置/目标：** D002；解释每个输出 feature 如何由全部输入 feature 加权形成，并独立推导矩阵尺寸。
**讲解链：** 点积做加权和 → 多列权重产生多个输出 → Y=XW；区分切片、局部分组、全维线性组合。降维不保证无损，一般线性投影也不等于几何上的正交投影。
**练习/交付：** 自选 4 维输入与 4×2 权重，逐项手算两个输出，再用代码核对；改变单个输入观察两个输出。构造一个 2→1 映射的不同输入同输出例子。
**验收/追问：** 换成 7→3 时 W 是什么 shape、每个输出用了哪些输入？为什么“看全部维度”仍可能丢信息？
**回补/衔接：** 乘法失败回 D002；信息损失失败回到最小反例；随后 D004。工程映射：Q/K/V 与 W_O 使用同类线性运算。

### D004｜概率、log/exp、统计量与 Softmax
**前置/目标：** D003 的向量概念；分清任意分数和归一化分布，为 Attention 和分类 Loss 准备基础。
**讲解链：** 相对分数 → exp 的正值 → 除以总和 → 概率分布；解释 log 的反函数直觉、均值和方差，不先要求背微积分。Softmax 不是排序或 Top-K。
**练习/交付：** 手算或计算三项 score 的 Softmax，验证非负与和为 1；所有 score 同加常数、整体放大时分别比较结果；标注归一化轴。
**验收/追问：** 为什么给全部 score 加相同常数不改变权重？沿错轴归一化为何可能仍得到“看似正常”的数字？
**回补/衔接：** 概率与指数不清则用两类别重算；随后 D005。产物：数值表、轴断言和一个错误归一化测试。

### D005｜PyTorch 张量操作与参数对象
**前置/目标：** D002–D004；能用基础张量操作表达线性计算，不把 API 名称当机制。
**讲解链：** tensor 的 dtype/device/shape → matmul、transpose、reshape、broadcast → 普通数据与可学习 Parameter；autograd 的原理留在 M02。
**练习/交付：** 用循环与矩阵运算实现同一批线性映射，比较数值；故意引入转置、广播和 dtype 错误各一个，写断言定位。记录实际框架版本。
**验收/追问：** reshape 为什么不能替代任意 transpose？为什么整数 token ID 与浮点权重不是同一种优化对象？
**回补/衔接：** shape 错回 D002/D003；只是不熟函数则查当日官方 API，不重讲数学；随后 D006。

### D006｜基础门槛与回补缓冲
**前置/目标：** D001–D005；确认能进入 Attention，而非宣布已掌握全部线性代数。
**练习/交付：** 无提示完成一组未见 B/N/D 的形状题、一项非方阵投影手算、一个广播 bug 修复和一个 Softmax 轴解释。保存原始答案与运行输出。
**验收/追问：** 能连贯说明数据轴、参数矩阵、输出轴及为什么降维可能有损；更换维度后仍正确。工程维度必须有代码证据，不能只凭口述判通过。
**回补/衔接：** shape→D002；线性组合→D003；分布→D004；代码→D005。通过后进入 D007；已稳定项不重复授课。本日兼作间隔复习，不强塞新主题。

## M01：Token、表示与 Attention（D007–D014）

### D007｜文本、Tokenizer、词表与 Token ID
**前置/目标：** D002/D005；从文本追踪到整数序列，不把 token 当作天然的一个字或词。
**讲解链：** 原始文本无法直接做数值计算 → tokenization → vocabulary 与 ID → encode/decode；用极小子词合并例子说明粒度，区分教学 tokenizer 与生产实现。
**练习/交付：** 用同一 tokenizer 编码中英文、空格和标点，记录 token 边界；实现一个小词表查表与未知项处理测试。语料使用合成或有授权文本。
**验收/追问：** 为什么 token ID 大小不表示语义远近？换 tokenizer 后旧 embedding 权重能否直接按原 ID 使用？
**回补/衔接：** ID/维度混淆回 D002；随后 D008。工程映射：token 预算、截断和 API 成本口径。

### D008｜Embedding 查表与 Contextual Representation
**前置/目标：** D007/D003；区分词表参数、单 token 初始表示、上下文更新后的表示与检索文本向量。
**讲解链：** ID 索引词表矩阵 → 初始 token embedding → 经过位置与上下文计算形成 hidden representation。向量值不普遍限定在 -1 到 1；特征通常没有预先命名的语义坐标。
**练习/交付：** 给小词表实现 embedding lookup；把同一 ID 放进不同位置和句子，标出哪些量起初相同、哪些量在后续计算中可变。训练来源仅登记 M02 依赖，不临时扩课。
**验收/追问：** 为什么不能直接把任意 token embedding 当作整段文档的高质量检索向量？
**回补/衔接：** ID/权重混淆回 D007；随后 D009。产物：四类表示的输入、shape、用途对照。

### D009｜RNN 到 Attention：信息路径复核
**前置/目标：** D008；利用已学历史，只验证长距离依赖与并行性的因果链，不整课重讲。
**讲解链：** recurrent hidden state → 逐步传递的路径 → LSTM/GRU 改善但仍递归 → Attention 的直接信息交互；避免“完全没有路径”和“长序列没有代价”。
**练习/交付：** 对一个长距离引用例子画两种信息路径，解释训练并行与生成顺序不是同一问题。已有独立证据者直接做新情境题。
**验收/追问：** 只换成 LSTM 是否消除了时间步依赖？Attention 为何不自动消除序列长度的资源成本？
**回补/衔接：** 只补失败的 hidden-state 或路径概念；随后 D010。

### D010｜单头 Scaled Dot-Product Attention
**前置/目标：** D003/D004/D008；从 X 到 Q/K/V，再到当前 token 的新表示。
**讲解链：** 匹配所需信息 → QK^T scores → 除以 sqrt(d_k) → 按 Key 轴 Softmax → 加权 V。d_k 是本次 Q/K 的宽度；输出不是新的 Q，也不是权重矩阵。
**练习/交付：** 对 N=3、d_k=2、d_v=2 的小例子逐步计算，打印 scores、weights、output 的 shape；检查每个 Query 的权重和。
**验收/追问：** N×N 与 N×d_v 分别表示什么？把 V 换掉、保持 Q/K 不变时哪些中间量改变？
**回补/衔接：** shape→D002/D003，权重归一化→D004；随后 D011。历史已通过流程不再反复问同一句确认题。

### D011｜Batch Attention、Causal Mask 与 Padding Mask
**前置/目标：** D010/D005；实现信息可见性约束，而不是依靠模型“自己不要看未来”。
**讲解链：** batch 内并行 → score 的两条位置轴 → mask 约束可见 Key → Softmax → 输出；区分 padding 与 causal 目的。全被遮挡的行必须有明确处理，不能任 NaN 传播。
**练习/交付：** 构造不同长度序列与 padding；改变未来 token，验证早期输出不受影响；检测被 mask 权重以及无效行。
**验收/追问：** mask 加在 Softmax 前还是后，各自会怎样？为什么 padding 的 loss mask 与 attention mask 不是同一个责任？
**回补/衔接：** 两条位置轴混淆回 D010；随后 D012。产物：至少正常、padding、未来扰动三类测试。

### D012｜位置表示及其适用边界
**前置/目标：** D010/D011；复核 sinusoidal 与 learned absolute PE 的动机、公式和边界。
**讲解链：** 无位置且无破坏该性质的 mask 时的置换关系 → 引入位置信号 → 同维逐元素相加 → 多频率 sin/cos。单频相位只确定到周期，不用真实钟表证明无限可区分；有界幅度不等于任意长度稳定泛化。
**练习/交付：** 计算小维度 PE，比较相邻及相隔较远位置；标明 512 维对应 256 对 sin/cos；分别写出固定 PE 与 learned PE 的参数属性。
**验收/追问：** ABC 与 CBA 的输出随输入重排和“原位数值完全相同”有何区别？causal mask 为什么要单独讨论？
**回补/衔接：** 三角基础不足单独回补相位与周期，不机械重问必要性；随后 D013。RoPE 系统比较在 D040。

### D013｜Multi-Head、Concat 与 W_O
**前置/目标：** D003/D010；闭合多头前向链路，区别独立投影、维度预算和输出融合。
**讲解链：** 共享同一个完整 X → 各自 W_Q/W_K/W_V → 各自 Attention → feature 轴 Concat → W_O 线性混合。512/8=64 是常见配置，不是独立视角的数学必要条件；不同 Head 也可能冗余。
**练习/交付：** 用 d_model=12、3 heads 推导所有矩阵 shape；为两个小 Head 手算一次 Concat 与输出映射；指出普通降维不是局部池化。
**验收/追问：** 每头都保持 512 维但用不同参数时能否有不同模式？Concat 已回 d_model 时 W_O 增加什么、又不保证什么？
**回补/衔接：** 投影→D003，单头计算→D010；随后 D014。不把“融合”一词的提示后复述直接计作独立掌握。

### D014｜Attention 实现、迁移验收与缓冲
**前置/目标：** D007–D013；形成 P1 的可测试 Attention 组件。
**练习/交付：** 仅使用基础张量操作实现小型 MHA；包含 Q/K/V 投影、mask、Concat、W_O，支持不同 N 和 head 数。写 shape、mask、重复输入与参考计算对照测试，记录浮点容差。
**验收/追问：** 无提示讲完整链路，并定位一个故意沿错轴 Softmax 的 bug；为什么不能由某头关注某词就断言它永久负责指代？
**回补/衔接：** 按失败定位 D003/D010/D011/D013；代码未完成写待完成，不用口头替代。通过后正式进入 M02。参考：V2 中原始 Transformer 与 PyTorch 官方资料；以实施时版本核对 API。

## M02：神经网络如何学习（D015–D026）

完整教案：[M02 T01–T08](../modules/M02-training-mechanisms.md)。以下把其中较大的单元拆成 12 个学习日，不改变原模块逻辑，也不把它变成 MHA 课尾的临时支线。

### D015｜T01：样本、目标、参数、超参数与 Loss
**前置/目标：** D003/D004；先定义“学什么”，再讨论参数如何改变。
**讲解链：** 数据与标签 → 当前参数做预测 → 目标函数量化差异 → 训练/验证分工；比较可学习参数与学习率等超参数。Loss 不是直接给每个参数下调节指令。
**练习/交付：** 对 y_hat=wx+b 的两组参数计算预测与平方误差，标出输入、目标、参数、输出与 Loss；提前保留未参与训练的数据。
**验收/追问：** 换输入与改权重有什么区别？为什么一次预测正确不代表训练完成？
**回补/衔接：** 参数/数据混淆回 D003/D008；随后 D016。产物：训练目标契约与计算表。

### D016｜T02A：从局部变化到导数
**前置/目标：** D015；把导数理解为局部敏感度，不默认已有微积分基础。
**讲解链：** 在相邻参数值重算 Loss → 变化量比值 → 更小步长下的局部斜率 → 导数符号与大小。梯度不是参数对错误的因果责任分数。
**练习/交付：** 对一元平方函数在三个位置计算对称有限差分，再推导解析导数并对照；记录 epsilon 太大或太小时的误差。
**验收/追问：** 导数为正时，参数小幅增大对 Loss 意味着什么？导数为零为何不等于找到全局最优？
**回补/衔接：** 斜率不清回到两次函数值比较；随后 D017，不直接堆大型公式。

### D017｜T02B：梯度下降与学习率
**前置/目标：** D016；能独立算出一次更新，并用反例解释步长风险。
**讲解链：** 单参数导数 → 多参数梯度 → 沿负梯度小步移动 → learning rate；w_new=w_old-eta*gradient。局部下降方向不是任意步长或验证指标改善的保证。
**练习/交付：** 对同一初始参数试三个步长，记录更新前后 Loss；保留一个过大步长变差的例子，并手算一次两参数更新。
**验收/追问：** 为什么梯度为正通常要减小参数？训练 batch Loss 下降能证明泛化提高吗？
**回补/衔接：** 符号错误回 D016；随后 D018。产物：参数、梯度、学习率与结果四列记录。

### D018｜T03A：链式法则与多参数共同学习
**前置/目标：** D016/D017；解释远离 Loss 的早期参数怎样获得更新信号。
**讲解链：** u=ax → y=bu → Loss；沿一条路径乘局部导数，多路径贡献相加。所有梯度对同一次前向的参数快照计算，再更新，不混用新旧参数。
**练习/交付：** 手画两个参数的计算图，计算 dL/da 与 dL/db，再共同更新；另做一个分叉后求和的小图。
**验收/追问：** 最后只有一个标量 Loss，为什么能得到两个不同梯度？同一参数出现在两条路径时如何处理？
**回补/衔接：** 链式乘法困难退回一条两节点路径；随后 D019。此处不要求先会矩阵 Jacobian。

### D019｜T03B：计算图、Backprop 与 Autograd
**前置/目标：** D018/D005；区分建图、计算梯度和修改参数。
**讲解链：** 前向保存中间量 → 反向沿依赖传播局部导数 → 叶参数累积梯度；autograd 是自动实现链式法则，不是另一种学习目标。
**练习/交付：** 用框架复现 D018 并对比手算；插入 detach 或不记录梯度的操作，观察哪些参数无法获得预期梯度；保存差异分析。
**验收/追问：** 调用 backward 后参数是否已改变？为什么一个能正常输出数值的图也可能无法训练预期参数？
**回补/衔接：** 图路径不清回 D018；随后 D020。官方读物：PyTorch Autograd，读机制段落而非背 API。

### D020｜T04：矩阵投影的梯度
**前置/目标：** D003/D018/D019；把标量链式法则推广到实际 W 矩阵。
**讲解链：** 从 Y=XW 的一个元素开始 → 上游 G=dL/dY → dL/dW=X^T G 与 dL/dX=G W^T → 样本/token 贡献聚合；先算一项再检查 shape。
**练习/交付：** 对小型非方阵手算一项和完整梯度，用 autograd 与有限差分交叉检查；明确精度、epsilon、容差。
**验收/追问：** 同一 W 被多个 token 使用时，其梯度来自哪里？为什么 X、W 与 G 的尺寸能判断公式是否写反？
**回补/衔接：** 矩阵乘法回 D003，链路回 D018；随后 D021。工程映射：W_Q/W_K/W_V/W_O 的共同基础。

### D021｜T05A：完整 Training Step 与训练循环
**前置/目标：** D019/D020；能够独立写出最小训练程序并解释执行顺序。
**讲解链：** batch → forward → Loss → backward → optimizer.step；补充梯度清零、梯度累积、epoch/step/batch、种子与 checkpoint。清零位置应与累积设计一致。
**练习/交付：** 写小网络训练脚本，打印一次更新前后的参数和梯度；故意漏掉 step、误用 detach、错误累积梯度，分别定位。
**验收/追问：** 为什么 backward 不等于 optimizer.step？批次翻倍时 step 与 epoch 的数量关系怎样改变？
**回补/衔接：** 只补出错步骤的依赖；随后 D022。产物：可运行脚本、配置、日志与三个失败用例。

### D022｜T05B：SGD、Momentum、Adam/AdamW 与训练状态
**前置/目标：** D017/D021；理解优化器为何不仅保存参数，还可能保存历史统计。
**讲解链：** SGD 更新 → Momentum 平滑历史方向 → 自适应统计的动机 → AdamW 的权重衰减边界；学习率调度、裁剪仅在稳定性问题下解释，不当作万能补丁。
**练习/交付：** 对同一小任务比较 SGD 与一种自适应优化器，记录参数、梯度和优化器状态；做保存/恢复一致性检查，不把一次结果推广为通用优劣。
**验收/追问：** 为什么只恢复权重不一定等价于继续原训练？出现 NaN 前应检查哪些证据？
**回补/衔接：** 更新方向回 D017，循环回 D021；随后 D023。实施时核对框架官方 optimizer 参数。

### D023｜T06A：分类、Logits、交叉熵
**前置/目标：** D004/D021；知道 token 预测的最终训练信号来自何处。
**讲解链：** 类别 logits → 概率 → 目标类别 → -log p(target) → 有效样本上的聚合；区分 vocabulary Softmax 与 Attention Softmax。实际损失 API 是否直接接收 logits 要核对，避免重复 Softmax。
**练习/交付：** 比较目标类别概率不同的三组分布之 Loss；实现小分类器，检查目标 ID 与类别轴以及 loss 聚合分母。
**验收/追问：** 预测最高概率类别不变时，Loss 为什么仍能变化？忽略 padding 后如何确定平均损失的分母？
**回补/衔接：** 概率/log 回 D004；随后 D024。

### D024｜T06B：泛化、数据划分与训练故障

### D025｜T07：从最终 Loss 回到所有 Head 与 W_O
**前置/目标：** D013/D020/D023；回答最初“是否分阶段训练”的问题，并解释机制而非复述结论。
**讲解链：** 最终 Loss → 下游层 → W_O → Concat 梯度分路 → 各 Head 的 weighted V、Softmax、QK^T → W_Q/W_K/W_V。标准全参数训练可联合优化；冻结、未连入图和零梯度是需要区分的设置。
**练习/交付：** 在小 MHA 后接分类输出，逐组检查参数梯度；冻结一组权重或切断一条路径后比较；不把非零梯度当作已经训练好。
**验收/追问：** Concat 没有可学习参数为什么仍参与反向传播？一次 step 是否保证每个参数非零更新、Loss 必然下降？

## M03 起始：完整 Transformer 的构件（D027–D030）

### D027｜FFN 与非线性
**前置/目标：** D013/D026；解释为什么 Attention 后还有逐 token 的特征变换。
**讲解链：** token 间信息混合 → 每个位置内部的特征变换 → 线性层之间的非线性；连续线性映射仍可合成线性映射，不能用更多矩阵替代所有非线性作用。
**练习/交付：** 实现小型 position-wise FFN，标注扩展与缩回维度；比较带/不带非线性的简单拟合任务，保存设置与结果。
**验收/追问：** FFN 是否直接在两个 token 之间做 Attention 式混合？两层线性之间删除激活会改变什么？
**回补/衔接：** 线性组合回 D003，训练实验回 D021；随后 D028。

### D028｜Residual Connection 与信息路径
**前置/目标：** D027/D018；理解 x+F(x) 的前向与梯度路径及 shape 条件。
**讲解链：** 深层变换难以只靠层层重写保持信息 → 增加恒等路径 → 学习增量；残差不等于把两段序列拼接，也不是保证训练永远稳定。
**练习/交付：** 为小 block 加 residual，核对两端 shape；手画梯度路径，比较有/无残差的受控小实验。
**验收/追问：** F(x) 近零时输出是什么？为什么残差两端维度要对齐，无法对齐时有哪些设计选择？
**回补/衔接：** 路径回 D018；随后 D029。产物：结构图文字描述、shape 测试与对照记录。

### D029｜LayerNorm、RMSNorm 与 Block 顺序
**前置/目标：** D004/D028；区分归一化的轴、统计量和可学习缩放，不把它当作位置编码。
**讲解链：** 特征尺度变化 → 每 token feature 轴统计 → 归一化与缩放 → LayerNorm/RMSNorm 的机制差别 → Pre-LN/Post-LN 的布局。一次实验不证明所有模型稳定性结论。
**练习/交付：** 对小向量手算均值/方差并核对 LayerNorm；标注 batch、sequence、feature 哪些轴被处理；搭出一种明确版本的小 block。
**验收/追问：** 为什么不是沿整批 token 求一个共同均值？归一化参数与输入统计量是否都通过训练保存？
**回补/衔接：** 统计量回 D004，残差路径回 D028；随后 D030。

### D030｜Encoder、Decoder 与 Cross-Attention
**前置/目标：** D011/D027–D029；以信息可见性和任务目标区分架构，而非只背名字。

**练习/交付：** 为检索编码、续写、翻译三个教学场景画数据流并标注 Q/K/V 来源；比较序列长度不同时 cross-attention score 的 shape。
**验收/追问：** Cross-Attention 的 Q 与 K/V 必须来自同一序列吗？“decoder”是否在所有架构里都包含 cross-attention？
**回补/衔接：** mask 回 D011，Q/K/V 回 D010；随后第二册 D031，把 block 接到词表预测与真实训练目标。
