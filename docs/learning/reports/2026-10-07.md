## 2. 今日核心理解

### 2.1 矩阵与 Projection
已能解释：
- X 为 6×8、W 为 8×5 时，Y 为 6×5。
- Y 的行仍对应 token，列对应新的 feature 维度。
- 一个输出元素来自 X 的一行与 W 的一列点乘；不是把输入维度分组压缩。

### 2.2 Token / Embedding
已能区分：
- Tokenizer：文本切分并映射到 Token ID。
- Token ID：词表索引，本身数字距离没有语义。
- Embedding lookup：按 ID 查初始向量。
- contextual representation：Transformer 结合上下文后形成的表示；同一 token ID 在不同上下文中可得到不同表示。

补充边界：
- 未登录词通常通过 subword / byte-level 等继续拆分，不等于信息必然丢失，但可能增加 token 数与计算成本。
- Tokenizer 能编码某语言，不代表模型真正理解该语言。
- 古今异义、一词多义、跨语言语义主要由训练后的上下文化表示处理，不由 Tokenizer 单独判定。

### 2.3 Position Encoding
已能独立说明：
- 无位置信息的 Self-Attention 本身没有 token 先后顺序线索。
- Position Encoding 提供结构化的位置线索，Transformer 学习如何利用这些线索。
- 对 sinusoidal PE 已建立“sin/cos 成对 + 多频率形成位置指纹”的直觉。
- 已理解 Token Embedding 与 Position Encoding 相加后不要求后续网络再唯一拆回两部分。

尚不把公式细节、相对位置性质记为稳定掌握；需要后续延迟验证。

## 3. 训练机制：今日进度

### Loss 与 Gradient
使用最小例子：
- 预测：ŷ = 2w
- ground truth：y = 10
- Loss：L=(2w-10)^2

已理解：
- Loss 是当前位置的误差度量；Gradient 是 Loss 对参数的局部变化率。
- 在 w=3 时 L=16，但 dL/dw=-16；在 w=7 时 L=16，但 dL/dw=+16。同样 Loss 不代表同样 Gradient。
- 导数描述当前位置的瞬时/局部变化率，不能拿 w=3 处的 -16 一直外推到很远的位置。
- Gradient 决定局部下坡方向；Learning Rate 与 Gradient 大小共同决定实际更新步长。
- Learning Rate 过大/过小与 Gradient Vanishing / Explosion 不是同一概念。

### 求导与 Chain Rule
已重新激活：
- 常数导数为 0。
- (aw+b)'=a。
- 幂函数基本求导规则。
- 复合函数通过 Chain Rule 传递局部变化率。
- 对 L=(2w-10)^2：dL/dw=2(2w-10)×2=4(2w-10)。

费曼理解：
- 每层只处理自己的局部变化率。
- 一个微小变化沿计算链传播时，各段局部变化率相乘，得到参数对最终 Loss 的总影响。

### 偏导与两参数 Backprop
最小模型：
- ŷ = xw1 + w2
- x=2, w1=3, w2=1, y=10
- ŷ=7, error e=-3, Loss=9

已理解偏导：
- 对哪个参数求偏导，就把该参数作为变量，其余独立参数暂时当常数。
- ∂ŷ/∂w1 = x = 2。
- ∂ŷ/∂w2 = 1。

反向链路已推进到：
- ∂L/∂e = 2e = -6。
- ∂L/∂ŷ = -6。
- ∂L/∂w1 = -6×2 = -12。
- ∂L/∂w2 = -6×1 = -6。
