# M02 — 神经网络如何学习：完整教学模块

版本：2026-10-06。状态：教学设计已建立，尚未授课与验收。

总路线：[CURRICULUM_V2.md](../CURRICULUM_V2.md)。本文件是完整的模块实施计划，不是已经完成的课程记录，也不是用一页术语替代教学。

## 1. 定位与目标

要解决的核心问题：一个最终 Loss 如何为前面许多层、多个 Head 和 W_O 提供参数更新信号？为什么通常可以联合训练，而不用先训练 Head 再训练输出矩阵？

目标是让学习者能够解释、手算、实现、排错，而不是只接受“通过反向传播端到端训练”这句话。最后须从数据与目标讲到梯度、更新、验证，并映射回 Transformer。

预算：约 10–14 小时有效学习与实验，划分为 T01–T08；每个单元可拆成多个短会话，不为了维持课数跳过前置知识。后续完整微型语言模型的实现计入 M03，而不在这里重复计时。

## 2. 入场诊断与依赖

需要：向量/矩阵 shape、线性组合、函数输入输出；简单 Python。概率、log/exp 的不足在 M00 回补。导数、链式法则、autograd 不作为默认前置，而是在本模块正式教学。

入场只抽查未验证项：能否解释 y=xW 的输入/参数/输出；能否区分数据改变与参数改变；能否读懂简单平方函数。诊断不是教学，也不把整套 Baseline 从头再来。

依赖：T01 → T02 → T03 → T04 → T05；T06 需要 M00 概率基础和 T01/T05；T07 需要 T04/T06 与 M01 Attention；T08 汇总前面结果。

## 3. 固定教学方法

每单元遵循：真实问题 → 直觉 → 最小可计算例子 → 必要公式与符号含义 → 学习者独立计算 → 小实验 → 1–3 个反例/边界追问 → 纠正 → 记录与延迟回测。

手算例子帮助理解，不替代整个训练理论；框架自动求导帮助验证，不替代独立解释。讲授时不提前展示验收题答案。不要求一开始就会大型 Jacobian 或矩阵微积分证明。

## 4. T01 — 什么叫“学会”：数据、目标、参数和 Loss

**前置：** M00 的函数与线性映射。

**动机：** 不先定义正确目标，就无法讨论参数该如何改变。

**教学顺序：** 固定参数做预测 → 与目标比较 → 定义 Loss → 可学习参数 vs 超参数 → 训练样本 vs 验证样本 → 一次更新不等于学会。

**机制与必要数学：** 从 y_hat=wx+b、平方误差开始；解释符号分别来自输入、当前参数与目标。再说明不同任务需要不同目标函数，不把所有训练都等同于平方误差。

**主动练习：** 给定输入、预测、目标，计算两种参数配置的 Loss；改变目标时比较哪个参数配置更好。

**产物：** 一张标明数据、参数、预测、目标、Loss 的计算表。

**验收：** 不看笔记说明训练究竟改变什么；能指出推理输入不同不代表权重在更新；分清参数、超参数和模型状态。

**常见错误：** Loss 直接指定某个参数该改多少；模型只要见过一个例子就学完；训练误差低就代表泛化好。

**未通过回补：** 只回到预测/目标/参数的区分，不急着引入梯度。

## 5. T02 — 导数、梯度与更新方向

**前置：** T01；平方函数和局部变化直觉。

**动机：** 当参数稍微改变，如何判断 Loss 会变大还是变小？

**教学顺序：** 两次近邻计算的差值 → 局部斜率 → 导数 → 多参数梯度 → 学习率 → 一次梯度下降。

**必要数学：** 先解释有限差分 [L(w+epsilon)-L(w-epsilon)]/(2epsilon)，再推导简单平方误差的导数；更新示意 w_new=w_old-eta*dL/dw。eta 是步长，不是置信度。

**练习：** 对一个未见过的数值例子，预测并算出更新方向；用不同 eta 比较更新后 Loss。保留一个步长过大导致变差的反例。

**产物：** 手算记录与有限差分对照。

**验收：** 梯度为正不等于“参数应该增大”；能解释为什么不保证任何步长都降低 Loss。

**错误与边界：** 梯度不是参数对错误的道德式“责任分数”；某个 batch 的下降不保证验证误差下降；零梯度不等于已经得到全局最优。

**未通过回补：** 回到局部改变与斜率，不背更新公式。

## 6. T03 — 链式法则与反向传播

**前置：** T02。

**动机：** Loss 离早期参数很远，不能只调最后一层。

**教学顺序：** 两段复合函数 → 每一段的局部导数 → 相乘传递 → 同一个参数影响多条路径时相加 → 前向存中间量 → 反向复用这些量。

**必要数学：** 以 u=ax、y=bu、L=平方误差为例，分别计算 dL/db 与 dL/da。一次联合更新使用同一次前向对应的参数值，不能更新 b 后不加说明地混用新的 b 求旧图的梯度。

**练习：** 学习者独立画计算图，标出局部导数并完成两个参数的一次联合更新；再做有分叉/汇合的例子。

**产物：** 可审查的手算计算图与数值结果。

**验收：** 能解释最终只有一个标量 Loss，为何仍可得到多个参数各自的梯度；能区分反向计算梯度与优化器修改参数。

**未通过回补：** 回到复合函数的一条路径，不用大模型图掩盖小例子的缺口。

## 7. T04 — 从标量到矩阵：Projection 的梯度

**前置：** T03、M00 矩阵乘法。

**动机：** 将刚学会的更新机制映射回 W_Q/W_K/W_V/W_O。

**教学顺序：** 每个输出是加权组合 → 每个权重如何影响输出 → 上游梯度 → 矩阵形式 → batch/sequence 上的求和。

**核心例子：** Y=XW。给定 G=dL/dY，则 dL/dW=X^T G，dL/dX=G W^T。先用 2–3 维数值解释一项，再检查整个 shape；暂不加入 bias，之后作为扩展处理。

**练习：** 对一个小矩阵逐元素算梯度并用有限差分核验；指出一个权重由哪些 token/样本共同贡献梯度。

**产物：** 手算与自动求导一致性检查；差异容差和数值精度明确记录。

**验收：** 理解“上游误差 + 当前输入”如何形成矩阵梯度，不能只背 X^T G。能解释一次 512→64 投影既不是分组池化，也不保证对任意输入无损。

**未通过回补：** 从矩阵中的一个输出、一项权重回到 T03。

## 8. T05 — 一次完整 Training Step

**前置：** T01–T04。

**动机：** 将数学连接到可执行训练程序。

**教学顺序：** 初始化 → batch → forward → Loss → backward → optimizer step → 下一批；解释 epoch/step/batch、学习率、梯度清零与梯度累积、随机种子、checkpoint。

**优化器深度：** 手算 SGD；理解 Momentum 与 Adam/AdamW 保存统计状态并改变更新方式的动机。此处不要求完整收敛证明，也不把 AdamW 说成所有场景最佳。

**实践：** 手写小网络训练循环；对照手算和 PyTorch autograd；输出更新前后的参数与梯度。使用梯度累积时明确其边界，不把“每次都 zero_grad”当成与设置无关的唯一规则。

**产物：** 一个可运行训练脚本、配置、日志、复现说明。

**验收：** 能说明 forward/backward/optimizer 各自做什么；区分梯度、参数、优化器状态；解释冻结参数或未进入计算图的参数为什么可能不更新。

**错误与边界：** 一次 step 不等于训练好；不是所有参数每步必然都有非零梯度；更新也不保证当前 Loss 或验证 Loss 每步都严格下降。

## 9. T06 — 分类目标、Softmax、交叉熵与泛化

**前置：** T05、M00 概率/log/exp。

**动机：** Transformer 最终预测 token，必须知道正确学习信号来自哪里。

**教学顺序：** logits → 类别概率 → 目标类别 → 负对数似然/交叉熵 → batch Loss → 训练/验证/测试 → 数据泄漏、过拟合与评估。

**必要数学：** 先解释单样本 L=-log p(target)，再讨论 batch/有效 token 的聚合；具体 API 是否接收 logits 要查文档，不能重复做不必要的 Softmax。

**练习：** 比较两组概率分布下目标类别的 Loss；设计一个泄漏例子；在小分类器上观察训练/验证曲线。

**产物：** 不含泄漏的数据划分与一份误差分析。

**验收：** 能区分 attention weights 的 Softmax 与最终类别 Softmax；知道梯度优化的是指定目标，不代表模型真实理解或所有业务指标都会同步改善。

**未通过回补：** 回到概率与目标，而不是只记“cross entropy”。

## 10. T07 — 映射回 Transformer 的联合训练

**前置：** T04、T06、M01 的 Attention/Multi-Head。

**动机：** 回答本次学习者提出的 Head 和 W_O 是否要分阶段训练。

**教学顺序：** 最终 Loss → 后续层/输出 → W_O → Concat 的梯度切分 → 各 Head → weighted sum、Softmax、QK^T → 各自 W_Q/W_K/W_V → 更前面的表示。

**强调：** 这是标准全参数训练的主线；冻结、PEFT、分阶段训练是其他设置，不把“永远全部一起训练”当作规则。Concat 前向不做学习性融合，反向仍能将梯度路由到对应输入；离散 token ID 本身不是需要优化的连续参数。

**实践：** 在小型多头层后接一个教学 Loss，检查 W_Q/W_K/W_V/W_O 的梯度 shape；冻结 W_O、断开一条路径、屏蔽部分位置，各做一次对照。M03 再把这个教学目标替换为完整语言建模目标。

**产物：** 参数—梯度—更新的追踪表及对照实验。

**验收：** 不用“因为可训练”结束回答；能沿图说明学习信号如何到达每个矩阵，并解释为何一次 forward/backward 可以支持联合更新，却不意味着一次训练完成。

## 11. T08 — 调试、工程迁移与独立答辩

**前置：** T01–T07。

**练习设置：** 从学习率为零/过大、断开梯度、目标错误、未预期的梯度累积、训练/验证泄漏等问题中安排至少两种。学生先定位，不提前告知答案；语言模型 label shift 的具体故障在 M03 验收。

**工程迁移：** 区分改善 prompt、增加 RAG 证据、修改工具执行逻辑、调整模型参数四类不同动作。不能见到系统效果差就默认要“再训练模型”。

**独立答辩：** 从样本和目标开始，解释一次训练闭环；指出自己如何验证梯度与学习行为；回答“为什么 Head 与 W_O 不必分开训练”和“训练 Loss 降低为何仍可能业务变差”。

**通过：** 手算、机制解释、运行产物与排错都有证据；某一项只看过示例则保持待验证。

## 12. 模块级达标标准

- Concept：区分参数、超参数、输入、目标、Loss、梯度、optimizer、训练与推理。
- Mechanism：独立计算一个两参数网络的链式梯度，能把计算图映射到矩阵和多头层。
- Engineering：训练脚本可复现，能检查梯度/冻结/数据划分并定位故障。
- Interview：不用笔记完成结构化解释并接受边界追问，不要求背全部优化器公式。

延迟回测用不同数值、不同小网络，不机械重复课堂原题。间隔按项目规则与实际状态安排；现在不虚构分数、通过日期或运行结果。
