## 预习：问题与知识地图

本单元回答“512→64 到底怎样算”。点积把对应元素相乘再求和，得到一个数；矩阵 W 的不同列提供不同的加权方式，产生多个输出特征。采用行向量约定：X 为 N×D，W 为 D×F，Y=XW 为 N×F。

## 核心框架与例子

本次手算示例：

```text
x = [1, 2, 3, 4]
W = [[ 1, 0],
     [ 0, 1],
     [ 1, 1],
     [-1, 0]]
y1 = 1×1 + 2×0 + 3×1 + 4×(-1) = 0
y2 = 1×0 + 2×1 + 3×1 + 4×0 = 5
```

一般式 y_j=Σ_i x_i W_ij。每个输出都可以使用全部输入维度，不是每 8 个数局部压成一个，也不是先挑出 64 个坐标。512→64 的数学 W 为 512×64；PyTorch Linear 存储的 weight 采用 out×in，实际算 x·weightᵀ，别把两种约定混用。

## 易错边界

“看全部维度”不等于无损。例如 W=[1,1]ᵀ，输入 [1,0] 与 [0,1] 都变成 1。一般 Linear Projection 不要求正交，也不意味着是二维/三维卷积。
