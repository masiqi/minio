# D028｜Residual Connection 与信息路径

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M03 · 前置：D027、D018

## 预习：问题与知识地图

深层网络不必每次完全重写输入。Residual 用 y=x+F(x) 保留一条恒等路径，同时学习一个增量。它既影响前向信息流，也为反向传播增加一条直接路径。

## 核心框架与例子

本次例：x=[1,-2]、F(x)=[0.5,0.5]，相加后 y=[1.5,-1.5]。若 F(x)=0，则 y=x，不需要子层另学一套恒等变换才能保留这个输入。

对应导数结构为 dy/dx=I+J_F(x)，I 是恒等路径，J_F 是子层对输入的局部导数。无需现在展开全部 Jacobian 元素，先用 D018 的两路径相加理解。残差相加的两侧必须兼容；需要变宽时可以设计额外投影，而不是随意拼接后假称相加。

## 易错边界

Residual 不是 Concat；它不增加 token 或并排保留两份向量。它也不保证任意深度、任意初始化和学习率都稳定。F(x) 与 x 相加后如何归一化，是 D029 另一项设计。
