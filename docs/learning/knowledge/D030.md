# D030｜Encoder、Decoder 与 Cross-Attention

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M03 · 前置：D011、D027–D029

## 预习：问题与知识地图

用“任务需要看什么信息”区分架构。Encoder-only 常用于双向编码；decoder-only 因果语言模型根据已知前缀续写；encoder-decoder 先编码输入，再条件生成输出。具体目标与 mask 要看设计，不能只由名字推断所有组件。

## 核心框架与例子

Self-Attention 的 Q/K/V 来自同一序列的表示。Cross-Attention 中，Q 来自当前待更新的序列，K/V 来自另一份供读取的表示；Query 数和 Key 数不必相等。

本次例：目标序列 2 个位置、来源序列 5 个位置，d_k=3、d_v=4。Q 为 2×3，K 为 5×3，V 为 5×4；QKᵀ 为 2×5；加权结果为 2×4。输出位置数由 Query 数决定，不是由来源文本长度决定。

原始 encoder-decoder 的 decoder 有读取 encoder 输出的 Cross-Attention；很多 decoder-only 模型没有这一步，不能把原始图无条件套到所有 LLM。

## 易错边界

Decoder 的 self-attention 可见性与 cross-attention 的来源约束不同。RAG 把检索证据拼入输入，不自动意味着模型内部新建了一层 Cross-Attention。
