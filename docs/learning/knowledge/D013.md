# D013｜Multi-Head、Concat 与 W_O

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M01 · 前置：D003、D010

## 预习：问题与知识地图

多个 Head 提供多组可学习的信息匹配与组合方式。它们读取同一个完整 X，各有 W_Q、W_K、W_V；不是将 token 分给不同 Head，也不是直接把原始特征硬切后各算一段。

## 核心框架与例子

每头：Q_h=XW_Qh，K_h=XW_Kh，V_h=XW_Vh；O_h=softmax(Q_hK_hᵀ/√d_k)V_h。最终 Y=Concat(O_1,…,O_H)W_O。

本次配置 N=5、D=12、H=3、每头 d_k=d_v=4：每个输入投影为 12×4；各头 Q/K/V 为 5×4；各头 weights 为 5×5；O_h 为 5×4；Concat 为 5×12；W_O 为 12×12；输出为 5×12。拼的是同一个 token 的不同特征，不是把 5 个 token 变成 15 个。

Concat 只是并排排列；W_O 让每个输出特征可线性组合所有 Head 的特征。它不是“每个专家一个概率权重”，也不保证下一层一定学到某种语义。

## 易错边界

512/8=64 是常见的宽度预算，不是不同视角成立的必要条件。同为 512 维但参数不同，仍可能有不同模式。固定总宽度时，参数和核心计算不按 Head 数简单倍增；每头仍有 N×N 关系，多头不消除二次序列计算。
