# D043｜偏好优化、对齐与适配风险

[目录](README.md) · [原教学卡](../daily/D031-D060-transformer-rag.md) · M04 · 前置：D024、D042

## 预习：问题与知识地图

示范告诉模型一种期望回答；偏好对比较两个候选哪一个更符合标准。RLHF 常以人类反馈训练奖励信号，再优化策略；DPO 提供直接利用偏好数据优化的方式。本单元要求解释目标和工程边界，不要求展开完整强化学习推导。

## 核心框架与案例

本次阅读助手场景：回答 A 简短但有准确引用；回答 B 流畅详细却编造出处。若标注者偏爱篇幅，偏好数据可能奖励 B。模型优化“更受偏好”并不自动优化事实正确、数据权限和任务结果。

一份偏好样本需要问题、候选、比较标准、标注依据和不确定性处理。训练、开发和保留评测应隔离；评价指标应覆盖被训练偏好没有充分表达的约束。奖励被利用时，模型可能提升评分而不是实际目标，需检查具体行为和失败案例。

## 易错边界

“对齐”不是单一数值，也不意味着消除了全部幻觉或风险。DPO 不是不需要数据或评价，只是不必照搬每种 RLHF 的训练流程。没有训练实验就不能声称方案已改善模型。

## 复习：先独立回答

1. 人类更喜欢的答案，为什么仍可能不适合企业系统？
2. 训练标准奖励礼貌，为什么不能只用礼貌评分验收？
