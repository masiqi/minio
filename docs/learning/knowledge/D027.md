# D027｜FFN 与非线性

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M03 · 前置：D013、D026

## 预习：问题与知识地图

Attention 让位置之间交换信息，FFN 则在每个位置内部重新变换特征。两类操作职责不同。典型 position-wise FFN 对各位置使用同一套参数，但分别计算，不直接把两个 token 混成一个。

## 核心框架与公式

常见形式：FFN(x)=σ(xW₁+b₁)W₂+b₂。W₁ 将 D 维映射到隐藏宽度 F；非线性 σ 改变可表达的函数类别；W₂ 再映射回 D。N×D 输入经过 N×F 中间层后回 N×D。

本次示例 D=4、F=10：W₁ 为 4×10，W₂ 为 10×4；token 数不变。若删除非线性，两层线性可合成 x(W₁W₂)，带 bias 时整体仍只是一个仿射变换；多堆矩阵不自动获得相同非线性表达力。

## 易错边界

FFN 的“逐位置”不意味着每个位置单独训练一套权重。中间扩宽也不是增加 token。Attention 中已有 Softmax 非线性，不代表 FFN 的非线性可以无代价删除。

## 复习：先独立回答

1. 输入 6×8，FFN 隐藏宽度 20、输出宽度仍为 8，各阶段 shape 是什么？
2. 为什么两层线性之间加激活，不只是为了把数值变小？

<details><summary>展开核对要点</summary>

6×8 → 6×20 → 6×8。非线性阻止整体简单合并为一个仿射映射，改变函数表达能力，而非仅控制幅度。

</details>

## 动手与达标证据

实现小 FFN，核对逐位置与批量结果；比较有/无激活的受控拟合任务。结果只是这个实验的证据，不推广成所有架构结论。
