# D012｜位置表示及其适用边界

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M01 · 前置：D010、D011

## 预习：问题与知识地图

不含位置或其他顺序信号、且没有破坏该性质的 mask 时，Self-Attention 对置换是等变的：输入行重排，输出对应重排；不是输出原位完全不变。位置表示让计算有机会利用先后与距离，Causal Mask 的顺序约束必须单独讨论。

## 核心框架与公式

经典正余弦方案令 ω_i=10000^(-2i/D)：PE(p,2i)=sin(pω_i)，PE(p,2i+1)=cos(pω_i)。p 是位置；i 是维度对编号；512 维对应 256 对频率，不是 512 个不同频率。sin/cos 同频成对，完整记录一个周期内的相位；只知 sin 值不能确定 cos 的正负。

本次例：D=4 时为 [sin p,cos p,sin(p/100),cos(p/100)]；p=0 得 [0,1,0,1]。位置向量与 token 向量逐元素相加，不增加 shape；原论文另外对 token embedding 做了 √D 缩放，使用哪种输入约定要说明。

同一频率移动 k 的变换可由角加公式线性表达；多频率让不同尺度共同编码位置。固定 PE 没有位置表参数；learned absolute PE 的位置表通过训练学习。

## 易错边界

有界幅度不保证任意长上下文泛化。周期、数值精度与有限适用范围都要考虑；不能用真实时钟类比证明无限唯一。直接加位置编号是尺度/设计问题，不是函数“不平滑”。
