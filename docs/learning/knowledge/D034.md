# D034｜P1：训练、验证与第一份误差分析

[目录](README.md) · [原教学卡](../daily/D031-D060-transformer-rag.md) · M03 · 前置：D026、D032、D033

## 预习：问题与知识地图

本日将微型模型接到真实训练循环。链路：正确 batch → 前向 logits → 有效目标 Loss → 反向梯度 → 更新 → 验证 → checkpoint。先检查可学习性，再讨论泛化，不用一条下降曲线代替整个证据链。

## 核心框架与案例

本次排错场景：小训练集的 Loss 长时间不变。先检查标签与 mask 是否正确、参数是否在更新、关键矩阵梯度是否符合预期，再检查学习率、尺度和实现；不是首先把 D 加倍。

可用极小数据过拟合测试来验证训练链路能否拟合简单规律。若能拟合，仅说明这项诊断成功；能否处理未见文本，要另外看划分正确的验证集及具体任务表现。

记录配置、seed、数据版本、有效 token 数、训练/验证模式、Loss 聚合方式与参数更新证据。train/eval 模式和是否记录梯度不是同一个开关，验证行为应显式设置。

## 易错边界

训练更久、训练 Loss 更低不等于产品更好。训练/验证数据不同且聚合分母不同，数值不能直接解释成泛化差距。没有真实运行，不把预计下降趋势写成结果。
