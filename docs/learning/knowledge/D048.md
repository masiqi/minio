# D048｜检索 Embedding、相似度、ANN 与过滤

[目录](README.md) · [原教学卡](../daily/D031-D060-transformer-rag.md) · M05 · 前置：D003、D008、D047

## 预习：问题与知识地图

Embedding 决定如何表示 query/document；相似度定义如何比较；索引决定如何高效搜索；ACL/metadata 过滤决定哪些候选合法。四层不能用“向量库”一个词全部代替。

## 核心框架与例子

点积 q·d 同时受方向与长度影响；cosine=(q·d)/(‖q‖‖d‖)，零向量需专门处理。向量都归一化后，点积等于 cosine。

本次 q=[1,0]，d₁=[2,0]，d₂=[1,1]：点积分别2和1；cosine 分别1和约0.707。d₁ 的长度翻倍会改变点积但不改变 cosine。哪个更适合，要符合模型训练与检索契约。

先有精确检索基线，再衡量 ANN 的速度/内存与近邻召回取舍。Filter 可能在不同阶段执行，既影响权限边界也影响候选数量和召回，实际实现需要测试。

## 易错边界

维度相同不代表不同 embedding 模型的空间兼容。换模型后通常需要重建文档向量或证明兼容性。相似文档不一定支持答案；ANN 的近邻 Recall 也不等于业务证据 Recall。

坐标语义和训练空间可能完全不同；尺寸匹配只保证可计算。权限是硬边界，应调整合法检索策略或说明证据不足，而非扩大授权。
