# D006｜基础门槛与回补缓冲

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M00 · 前置：D001–D005

## 预习：本单元不是新的一章

要把“知道名词”变成能从数据含义推导计算。复习地图：样本/位置/特征 → shape → 线性组合 → 参数矩阵 → 输出 → 归一化轴 → 可重跑证据。无需预先会反向传播，尚未要求掌握全部线性代数。

## 核心框架与示范

本次示范任务：X 为 3×4×5，W 为 5×2。Y=XW 得到 3×4×2，表示每条序列 4 个位置、每个位置 2 个输出特征。若对 Y 最后轴做 Softmax，是在每个位置的两个输出之间归一化；它不是 4 个位置间的 Attention。

四种证据分开看：能命名轴是概念；能推出新尺寸和数值是机制；能运行并修 bug 是工程；能不靠提示解释错误为何发生是表达。读本卡只属于复习，不是验收通过。

## 易错边界

会算 512/8 不等于知道 QKᵀ 为什么是 N×N。重复刚给出的数字不能证明迁移。环境没装好与数学没理解，也不能混成一个低分。

2. 构造一个“shape 相同但含义不同”的例子，并说出断言之外如何检查。
