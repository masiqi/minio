# D014｜Attention 实现、迁移验收与缓冲

## 预习：复习地图

这是 P1 的组件门槛，不再添加一种 Attention。需要连通：X → 各头可学习投影 → score → scale → mask → Key 轴 Softmax → weighted V → feature Concat → W_O。每个箭头都要有输入、输出与轴语义。

## 核心框架与示范

本次测试配置：B=2、N=3、D=8、H=2。投影后重排为 B×H×N×4；scores 为 2×2×3×3；单头输出合在张量中为 2×2×3×4；恢复 token/feature 布局并拼接后为 2×3×8。

一个重要检查不是“结果像向量”，而是改变未来 token 后早期输出是否不变、每个有效 Query 的权重是否正确归一化、循环参考实现与矩阵实现是否在容差内一致。重复输入实验要明确是否加了位置和 mask。

## 易错边界

维度刚好相同会隐藏错轴 bug，因此不能只测方阵或固定 N。参考实现和待测实现共享同一个错误，也可能彼此一致，需要独立的手算例子。某头一次关注代词不证明永久分工。
