# D004｜概率、log/exp、统计量与 Softmax

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M00 · 前置：[D003](D003.md)

## 预习：问题与知识地图

分数可以为负且无总和约束；概率描述规定候选集上的分布。exp 把实数变成正数，log 是它的反函数。Softmax 用 exp(score) 除以同组所有 exp 的总和，建立相对权重，而不是选出前几名。

## 核心框架与例子

本次示例：scores=[0,ln2,ln3] → exp=[1,2,3] → weights=[1/6,2/6,3/6]。一般式 p_i=exp(s_i)/Σ_j exp(s_j)。整个过程保持向量长度；对矩阵哪一轴归一化，取决于哪些对象在相互竞争。

所有分数同加 c 时，分子分母共同乘 exp(c)，结果不变；整体乘大于 1 的系数通常让分布更集中，不是同一性质。数值实现常先减最大分数，利用的就是前一条。

均值描述中心；方差描述相对均值的平方偏离的平均；标准差是方差开根。它们不等于概率，也不意味着数据必然正态分布。

## 易错边界

Attention 中每个 Query 在允许的 Key 上分配权重，不是全矩阵所有数共用一个总和。非负且和为 1 只是基本性质，不能证明语义或轴选择正确。
