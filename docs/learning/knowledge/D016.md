# D016｜T02A：从局部变化到导数

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M02 · 前置：[D015](D015.md)

## 预习：问题与知识地图

想知道参数该往哪边改，先比较它小幅变化时 Loss 怎样变。差值给出变化量，差值除以步长给出平均斜率；在足够小的邻域内，导数描述局部敏感度。多参数时，对每个参数单独求偏导，其他量暂时固定。

## 核心框架与例子

本次取 L(w)=(w-3)²。展开 L(w+ε)-L(w)=2(w-3)ε+ε²，除以 ε 后令 ε 趋近 0，得到 dL/dw=2(w-3)。w=1 时导数 -4；w=3 时为 0；w=5 时为 4。

数值检查可用 [L(w+ε)-L(w-ε)]/(2ε)。它不是训练所用反向传播的替代算法，而是小实验里核对解析梯度的方法。ε 太大不够局部，太小可能受浮点误差影响。

## 易错边界

导数不是“这个参数造成了几成错误”的因果责任分数。零导数一般只说明局部一阶变化为零，可能是极小、极大或其他驻点；不能直接宣称全局最优。本例的 w=3 是最小值，要靠具体函数判断。

## 复习：先独立回答

1. L(w)=(w-2)²，w=0 的导数是多少？小幅增加 w 会怎样？
2. 梯度为零和 Loss 为零是同一件事吗？

<details><summary>展开核对要点</summary>

导数为 -4，足够小的正向移动使 Loss 降低。不是同一件事，例如常数正损失函数导数为零但损失不为零。

</details>
