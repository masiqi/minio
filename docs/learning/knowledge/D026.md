## 预习：训练机制的完整地图

本日不新增训练算法。复习链：样本/目标 → 前向参数化计算 → Loss → 局部导数 → 链式法则 → 梯度汇总 → 优化器更新 → 重复训练 → 独立验证。要能说明每一步做什么，也能定位缺失一步的表现。

## 核心框架与示范

本次小图：x=1、a=2、b=3、y=5，预测 abx=6，L=½(6-5)²=0.5。当前 da=3、db=2；η=0.1 时共同更新为 a=1.7、b=2.8。这里梯度来自同一个旧参数快照，不用更新后的 a 再算 db。

同样逻辑可以沿矩阵和 Attention 运算传播，不需要给每个 Head 单独发一个标签。工程上则需要明确参数组、梯度清零、目标轴、有效 Loss 位置和 checkpoint 状态。

## 易错边界

会背 forward→backward→step 不等于会训练。能跑现成脚本也不证明可以诊断 detach、标签错误或梯度意外累积。看到学习率名词不代表能解释优化器历史状态。
