# D029｜LayerNorm、RMSNorm 与 Block 顺序

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M03 · 前置：D004、D028

## 预习：问题与知识地图

本单元分清“在哪里统计”“怎样归一化”“哪些量可学习”。在常见语言模型布局中，对每个 token 的 feature 轴计算统计，而不是把整个 batch/sequence 混成一个平均数。

## 核心框架与例子

LayerNorm：y=γ⊙(x-μ)/√(σ²+ε)+β。μ/σ² 来自当前输入特征；γ/β 是可学习缩放与偏移。常见 RMSNorm：y=γ⊙x/√(mean(x²)+ε)，不做均值中心化；具体实现的 bias 等选项要核对。

本次示例 x=[1,3]，为手算忽略 ε、令 γ=1、β=0。LayerNorm 的 μ=2、方差=1，结果 [-1,1]；RMSNorm 分母 √5，结果约 [0.447,1.342]。两者不是同一个算式。

Pre-LN 的一种子层写法是 x+F(Norm(x))；Post-LN 是 Norm(x+F(x))。布局改变信息和梯度路径，不只是代码书写顺序。

## 易错边界

输入均值不是每次训练后固定存下来的模型权重；参数与输入统计量不同。Norm 不提供位置编码，不是把输出变成概率。常见 feature 轴用法不代表 API 不能配置其他 normalized_shape。
