# D021｜T05A：完整 Training Step 与训练循环

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M02 · 前置：D019、D020

## 预习：问题与知识地图

训练循环将数据、前向预测、损失、梯度与更新组织起来。Batch 是一次处理的数据组；step 通常指一次参数更新；epoch 是遍历一次训练集。梯度累积时，多个小 batch 的反向可以合并成一个更新 step。

## 核心框架与例子

本次顺序示意（不是完整可运行脚本）：

```python
optimizer.zero_grad()
prediction = model(inputs)
loss = loss_fn(prediction, targets)
loss.backward()
optimizer.step()
```

清零防止上轮梯度无意混入；forward 用当前参数计算；Loss 定义优化目标；backward 计算梯度；step 才修改受管理参数。若设计了梯度累积，清零与更新频率必须跟累积窗口一致，Loss 的缩放也要对应目标。

例：120 个样本、batch=12、每 batch 更新、不丢尾部时，一个 epoch 有 10 steps；改为 batch=24 则为 5 steps。此结论依赖没有梯度累积等额外条件。

## 易错边界

能计算 Loss 不代表参数在变。遗漏 step、参数未交给优化器、detach、错误标签或清零位置都可能破坏训练。不要将所有 Loss 不降都解释成学习率太小。
