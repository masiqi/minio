# D010｜单头 Scaled Dot-Product Attention

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M01 · 前置：D003、D004、D008

## 预习：问题与知识地图

一个位置要用相关位置的信息更新表示：Q/K 负责匹配，V 提供被组合的内容。单头先从 X 通过各自可学习矩阵得到 Q、K、V，再计算 O=softmax(QKᵀ/√d_k)V。Softmax 沿 Key 轴进行。

## 核心框架与例子

Q、K 为 N×d_k；V 为 N×d_v；scores 和 weights 都是 N×N，最终 O 是 N×d_v。d_v 不必等于 d_k。某一行的结果是一个 token 的新表示，不是“新的 Q”或一组权重。

本次例子：某 Query 的 weights=[0.2,0.3,0.5]，三个 V 依次为 [2,0]、[0,4]、[2,2]，输出为 [1.4,2.2]。这是两个特征，不是三个位置概率。对所有 Query 都算，才组成输出矩阵。

在零均值、单位方差及相应独立性假设下，点积方差随 d_k 增长，标准差随 √d_k 增长；除以 √d_k 控制典型尺度，不是把分数变成概率，也不保证任何极端输入都稳定。

## 易错边界

一个 token 对所有 V 加权相加，维度仍为 d_v。score 不等于 weight；矩阵相乘不是逐元素相乘；正常 Softmax 不执行 Top-K 硬选择。

2. 固定 Q/K，只改变 V，哪些量会变？

<details><summary>展开核对要点</summary>

7×7 与 7×5。scores/weights 不变，输出通常变化；这是匹配机制与传递内容的职责分离。
