# D031｜Hidden States、LM Head 与 Vocabulary Logits

[目录](README.md) · [原教学卡](../daily/D031-D060-transformer-rag.md) · M03 · 前置：D023、D030

## 预习：问题与知识地图

本单元回答“表示怎样回到文字”。通常不是把 hidden representation 反解成原字符，而是用它预测下一个 token。链路：最终 hidden states → 词表线性映射 → logits → 选择或采样 token ID → tokenizer decode。训练时还把 logits 与目标 ID 联系起来计算 Loss。

## 核心框架与例子

为避免与 Value 矩阵混淆，本卡用 C 表示词表大小。H 为 B×N×D，数学权重 U 为 D×C，Z=HU 为 B×N×C。每个位置有 C 个候选分数，不是 C 个 D 维语义向量。

本次例：h=[1,2]，U=[[1,0,-1],[0,1,1]]，得到 logits=[1,2,1]。词表三个 ID 分别对应三个候选 token；这些数还不是概率。先对候选轴归一化，再按生成策略选择。对于 512 维表示和 50000 词表，单位置输出是 50000 个分数。

某些模型共享输入 embedding 与输出映射的权重；采用行向量约定时可用 U=Eᵀ。这是设计选择，不能假定所有模型都共享。

## 易错边界

Attention Softmax 的候选是 Key 位置，LM 输出 Softmax 的候选是词表 token。生成一次 token 不等于生成一个汉字。整层输出是分数张量，选择之后才得到离散 ID。
