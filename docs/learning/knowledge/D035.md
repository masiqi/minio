# D035｜P1：Checkpoint、恢复与自回归生成

[目录](README.md) · [原教学卡](../daily/D031-D060-transformer-rag.md) · M03 · 前置：D022、D034

## 预习：问题与知识地图

训练时整段序列已知，可组织多个位置的预测；生成时未来 token 还未知，要逐步选择并扩展前缀。Checkpoint 则让模型行为和训练状态能被保存与重建，两者都不能只保存最后输出的文字。

## 核心框架与例子

本次生成示意：[A,B] → 取最后位置 logits → 选 C → 新输入 [A,B,C] → 再预测下一项。最简 greedy 取候选最大值；EOS、最大长度和外部取消都应有明确停止规则。更复杂采样在 D038。

只做推理通常需模型权重、结构配置、tokenizer 与相关版本；继续训练还可能需 optimizer、scheduler、步数、随机状态和数据进度。环境改变时，不能保证所有实现逐位一致，应定义合理数值容差。

保存/加载检查先比较同一输入的 logits，而不是只看两次文本碰巧一样；相同选中 token 可能掩盖分数已经偏移。

## 易错边界

训练并行不等于可以独立预测所有未知未来 token。只存 state_dict 不代表别人知道如何构造相同模型和词表。不要从不可信来源加载可执行或不安全的序列化对象。
