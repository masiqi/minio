# D022｜T05B：SGD、Momentum、Adam/AdamW 与训练状态

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M02 · 前置：D017、D021

## 预习：问题与知识地图

普通 SGD 使用当前梯度；Momentum 引入历史方向；Adam 使用梯度的一阶、二阶历史统计来调整更新；AdamW 将权重衰减与自适应梯度更新解耦。它们改变更新规则，不替代 Loss 与 Backprop。

## 核心框架与例子

概念式 Momentum 可写成 v_t=βv_(t-1)+g_t、θ_t=θ_(t-1)-ηv_t；具体库还可能有 dampening 等配置，应对照版本。

本次例：β=0.9、旧 v=2、当前 g=-1，则 v_new=0.8。虽然当前梯度为负，历史动量仍使这次 v 为正。这说明同样参数和当前梯度，在不同优化器历史下可能产生不同更新。

Adam 维护类似移动平均的一阶和平方梯度统计，并做相应偏差校正；AdamW 的衰减不是简单把同一个 L2 梯度丢进所有自适应统计就完事。这里要先掌握各状态的职责，再读实现公式。

## 易错边界

只恢复模型权重不一定恢复同一训练过程，还可能需要 optimizer、scheduler、步数、随机状态及数据迭代位置。梯度裁剪与学习率调度不是隐藏错误标签或 NaN 的万能补丁。不能凭一次实验判定 Adam 永远优于 SGD。

2. 只做推理和继续训练，对 checkpoint 的要求有什么不同？
