# D036｜P1 门槛：完整 Transformer 解释、实现与排错

[目录](README.md) · [原教学卡](../daily/D031-D060-transformer-rag.md) · M03 · 前置：D027–D035

## 预习：三条不能混淆的链

前向链：文本 → IDs → 表示 → block → logits。训练链：logits+正确目标 → Loss → 梯度 → optimizer → 新参数。生成链：已有前缀 → 下一 token 分布 → 选择 → 扩展前缀。三条相互连接，但不是同一个过程。

## 核心框架与示范

本次复习任务：给一个 B×N 的 ID batch，逐层标注表示轴和词表轴，再指明哪些量是数据、哪些是模型参数、哪些是输入相关的中间结果。对训练，指出 label shift 和可见性；对生成，指出为什么只对当前已有前缀作选择。

排错时按数据、目标、结构、梯度和运行状态分层。例如输出形状正确但答案复制输入，可优先检查标签和 mask；Loss 有值但更新为零，应查图与优化器，而非继续修改采样温度。

## 易错边界

本门槛验证的是微型模型机制，不是大规模预训练或生产语言质量。背完整箭头链仍不足以定位错误；漂亮生成样例也不能代替验证集和未来扰动测试。
