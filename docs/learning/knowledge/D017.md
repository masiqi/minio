# D017｜T02B：梯度下降与学习率

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M02 · 前置：[D016](D016.md)

## 预习：问题与知识地图

梯度给出局部变化方向，优化器根据它提出更新。普通梯度下降写成 θ_new=θ_old-η∇L；η 是学习率。负梯度是局部下降方向，不意味着任意大的一步都能下降。

## 核心框架与例子

继续用 L(w)=(w-3)²，w=1 时 L=4，梯度为 -4。本次示例：η=0.25，w_new=1-0.25×(-4)=2，L_new=1；η=2，w_new=9，L_new=36，反而更差。

多个参数的梯度组成一个向量；各项是在同一次前向参数状态下求得，再按更新规则一起应用。Step 是一次参数更新，不是整个训练完成；训练往往反复处理多个 batch。

## 易错边界

“梯度为正就加参数”会走反。更大的梯度不说明参数一定更重要，也可能受到尺度影响。一个 batch Loss 降低不保证验证数据、任务成功率和安全性同步提高。
