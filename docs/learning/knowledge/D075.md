# D075｜Grader、人工校准与不确定性

[目录](README.md) · [原教学卡](../daily/D061-D090-agent-production.md) · M08 · 前置：D004、D024、D074

## 预习：问题与知识地图

评委本身也可能错。先选能直接检查的 code grader，再为开放质量制定 rubric，使用 model grader 时与人工标注对照。区分任务歧义、评分器错误、模型错误，以及有限样本带来的不确定性。

## 核心框架与案例

本次对照：两份答案事实相同，B 更冗长。若 judge 因篇幅总给 B 高分，应检查 rubric、顺序效应和样本，而不是直接认定 B 的系统更强。保留分歧与人工理由，修订后用新样本复查。

对于重复 trial，报告成功数/总数与测试条件，例如“8/10”，而不是只写“80%准确”并当作稳定总体概率。同一个错误环境或缓存污染全部 trial 时，它们并非可靠的独立重复证据；样本多也可能只是重复同一偏差。

## 易错边界

人工标注也需要标准与分歧处理。Judge 的高置信语气不是事实证据。根据测试集不断修改评分规则再报告提升，会模糊开发与保留评价的边界。

## 复习：先独立回答

1. Judge 与模型一致同意某答案，为什么仍可能一起错？
2. 10次试验全用未重置的同一环境，成功率有什么解释风险？

<details><summary>展开核对要点</summary>

可能共享错误知识、偏好或缺失证据，需要独立可核验标准。环境残留可能帮助或妨碍后续试验，观察不能直接当作独立同条件任务的稳定成功概率。

</details>

## 动手与达标证据

人工标注一组输出，与自动评分对照并记录误报/漏报；固定任务重复运行，说明样本量与依赖限制。回补：D004/D024。衔接：[D076](D076.md)；依据：[S22](SOURCES.md#s22)。
