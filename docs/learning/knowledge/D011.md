# D011｜Batch Attention、Causal Mask 与 Padding Mask

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M01 · 前置：D010、D005

## 预习：问题与知识地图

模型训练时不能读取应当预测的未来信息；同批序列为对齐长度添加的 padding 也不该被当成普通证据。知识链：B 个样本 → Query/Key 两条位置轴 → 规定可见位置 → Softmax → 加权 V。

## 核心框架与例子

本次示例用 3 个位置，允许当前及以前的位置：

```text
可见性（行=Query，列=Key）
[1,0,0]
[1,1,0]
[1,1,1]
```

常见实现对不允许的 score 加 -∞，再做 Softmax，使其权重为 0。这里允许当前 token，因为当前输出用来预测下一个 token。Padding Mask 处理无效位置；Loss Mask 决定哪些目标计入训练损失，不能相互替代。

单头 batch 的 scores 为 B×N×N；多头再增加 head 轴。Mask 广播时必须确认映射到正确样本、Query 和 Key，不能只验证最终大小。

## 易错边界

Softmax 后直接把部分权重清零且不重新归一化，并不等价于标准 masked Softmax。全行均被遮挡时没有有效分布，应明确拒绝、跳过或其他有效行策略，不能放任 NaN。不同库的布尔 mask 含义要查版本。
