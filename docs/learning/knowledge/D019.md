# D019｜T03B：计算图、Backprop 与 Autograd

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M02 · 前置：D018、D005

## 预习：问题与知识地图

Autograd 不是另一个学习目标，而是自动组织链式法则的工具。前向计算产生值与依赖；反向从 Loss 沿图计算局部导数并累积；优化器随后使用梯度更新参数。这三件事必须分开。

## 核心框架与例子

本次沿用 u=ax、y_hat=bu。正常图中，Loss 可影响 a 和 b；若计算 y_hat=b·detach(u)，数值前向仍能得到同一个预测，但到 a 的这条梯度路径被切断，b 仍可通过 u 的数值求梯度。

检查对象：参数是否需要梯度；运算是否被记录；参数是否连到 Loss；叶参数的 .grad 是否存在；参数是否交给 optimizer。非叶张量默认不保留 .grad，不代表链式传播没有经过它。

## 易错边界

backward() 通常只计算/累积梯度，不自动做 optimizer.step()。冻结参数与把整段计算 detach 不完全相同：有时需要固定某矩阵，但仍通过它向更早的可训练部分传梯度。

## 复习：先独立回答

1. Loss 正常输出，但某参数 .grad 为 None，是否一定是数学导数恰好等于 0？
2. 只调用 backward、不调用更新，参数会因为梯度存在而自行改变吗？

<details><summary>展开核对要点</summary>

None 与数值零不同，需检查记录、连接、requires_grad 和清零行为。普通训练中不会自动更新，优化器或显式更新代码负责修改参数。

</details>
