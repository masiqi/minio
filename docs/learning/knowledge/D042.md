# D042｜Pretraining、SFT 与 LoRA/PEFT

[目录](README.md) · [原教学卡](../daily/D031-D060-transformer-rag.md) · M04 · 前置：M02、D036

## 预习：问题与知识地图

先问改变的是目标、数据还是可训练参数。Pretraining 学基础分布；SFT 用示范数据优化指定任务/指令行为；PEFT 描述只训练部分参数或增量的一类方法。SFT 与 LoRA 不在同一分类轴上，可以一起使用。

## 核心框架与例子

采用行向量约定，基础映射 y=xW₀；低秩增量可写成 y=x(W₀+sAB)，A 为 D×r，B 为 r×F，s 为缩放。W₀ 可冻结，A/B 通过 Loss 学习；推理时总映射已改变，所以冻结基座不等于输出不变。

本次示例 D=8、F=6、r=2：完整权重有48个数，A/B 共16+12=28个数，未计 bias 等其他参数。是否显著节约取决于 r 和实际更新范围，不是只要叫 LoRA 就一定更少。

训练数据契约仍要记录示范来源、目标格式、权限、划分和反例；微调并不是可靠的实时知识数据库。知识频繁更新时，外部检索与引用往往是需要比较的另一条方案。

## 易错边界

不能把“预训练、SFT、LoRA”排成所有模型必经的三阶段。低秩约束影响可表达的增量，不保证任何任务无损。参数更少不免除数据质量和验证要求。
