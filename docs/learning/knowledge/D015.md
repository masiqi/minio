# D015｜T01：样本、目标、参数、超参数与 Loss

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M02 · 前置：D003、D004

## 预习：问题与知识地图

训练先要定义“学什么”，才能讨论怎样改参数。输入 x 是已知条件，目标 y 是监督信号，参数 θ 决定当前模型函数，预测 y_hat 是结果，Loss 量化这次预测与目标的差异。学习率等超参数规定学习过程，不等于模型在前向中使用的所有可学习权重。

## 核心框架与例子

本次定义 y_hat=wx+b，单样本 L=½(y_hat-y)²。取 x=2、y=5：w=1、b=0 时预测 2、Loss=4.5；w=2、b=1 时预测 5、Loss=0。改变输入是在问不同问题，改变 w/b 是修改模型。

Loss 给出一个可优化目标，不会直接告诉每个参数“应该加几”。导数、链式法则和优化器在后续单元补齐。样本集合上通常聚合多个损失；聚合方式会影响梯度尺度，必须说明 sum 还是 mean。

## 易错边界

在一个样本上 L=0 不代表未知数据都正确。训练数据用于优化，验证数据用于检查和选配置，最终测试需保留独立边界。业务成功也不一定被某个训练 Loss 完全描述。
