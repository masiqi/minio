# D009｜RNN 到 Attention：信息路径复核

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M01 · 前置：[D008](D008.md)

## 预习：问题与知识地图

沿用历史已学内容，只补信息路径的因果，不重新背 Transformer 的优点。RNN 用 h_t=f(h_(t-1),x_t) 更新状态；更早的信息要经过连续状态转换，才能影响较晚的位置。LSTM/GRU 改善保存和更新方式，但仍有时间步递归依赖。

## 核心框架与例子

本次例子：第 2 个位置介绍人物，第 20 个位置出现指代。RNN 的信息要经过中间状态；一层允许这两个位置互相可见的 Attention，可以直接建立二者的加权交互，不必逐个经过所有中间 token。

这里缩短的是信息交互路径，不是删除一切计算路径。密集 Attention 仍需比较多个位置。训练中已有整段输入，可以并行组织位置间计算；自回归生成中未来 token 尚未获得，仍要逐步扩展前缀。

## 易错边界

“RNN 完全不能学长依赖”“Attention 没有路径”“Transformer 一次生成所有未来 token”都过头。位置编码提供位置线索，不是缩短递归路径的原因；mask 又限制哪些位置允许交互。

门控改善跨步信息保留，但当前状态仍依赖前一状态。密集交互涉及位置对，N 个 Query 与 N 个 Key 形成 N² 个关系；并行不等于没有总计算量。
