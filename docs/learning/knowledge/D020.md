# D020｜T04：矩阵投影的梯度

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M02 · 前置：D003、D018、D019

## 预习：问题与知识地图

前向 Y=XW 中，每个权重参与多个样本或 token 的计算。反向要汇总这些使用处的梯度贡献，而不是为每个 token 单独训练一套 W。先理解一个元素，再使用矩阵记法。

## 核心框架与公式

采用 X∈R^(N×D)、W∈R^(D×F)、Y∈R^(N×F)，上游 G=dL/dY 也为 N×F。由 Y_ij=Σ_k X_ik W_kj：

```text
dL/dW = XᵀG       → D×F
dL/dX = GWᵀ       → N×D
```

本次例：X=[1,2]，W 为 2×2 单位矩阵，G=[3,4]。则 dW=[[3,4],[6,8]]，dX=[3,4]。有多个样本时，矩阵乘法已包含沿 N 轴累加；若上游 Loss 做 mean，平均因子已在 G 内，不要再随意除一次。

## 易错边界

梯度 shape 与所求导对象一致，但只验证 shape 还不能证明数值正确。权重存储采用转置约定的库，其代码表达可能不同，需要先对齐数学约定。

## 复习：先独立回答

1. X 为 4×3、W 为 3×2，G、dW、dX 各是什么 shape？
2. 一个 W 被 100 个 token 使用，它的更新依据是最后一个 token 还是全部相关贡献？

<details><summary>展开核对要点</summary>

G 为 4×2，dW 为 3×2，dX 为 4×3。共享参数汇总全部路径的贡献；不是最后一项覆盖前面的梯度。

</details>

## 动手与达标证据

手算非方阵的一项及全部梯度，用 autograd 和有限差分核对，记录 epsilon、dtype、容差；该对照才是工程证据。
