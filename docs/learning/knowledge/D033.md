# D033｜P1：拼装一个微型 Decoder-only Transformer

[目录](README.md) · [原教学卡](../daily/D031-D060-transformer-rag.md) · M03 · 前置：D014、D027–D032

## 预习：问题与知识地图

目标是把组件接成可解释的完整前向模型，不要求此时生成流畅语言。链路：整数输入 → Embedding/位置 → 一至两层因果 Attention 与 FFN → Residual/Norm → LM Head。先明确一种结构，不把不同论文的布局随意混在一起。

## 核心框架与例子

本次教学配置：B=2、N=5、D=8、H=2、词表 C=20、FFN 宽度 F=16。输入 IDs 为 2×5；lookup 后为 2×5×8；每头宽 4；经过 block 后仍为 2×5×8；LM Head 输出 2×5×20。

可采用明确的 Pre-LN 子层组合：x←x+Attention(Norm(x))，再 x←x+FFN(Norm(x))；是否最终再加 Norm 由配置说明。PE、mask、dropout 和 weight tying 的选择都应写清，不以“标准 Transformer”掩盖未决定的细节。

## 易错边界

调用完整 Transformer 黑盒只证明会使用接口，不完成本单元的组件理解目标。输出 shape 正确也不能证明因果 mask 正确。未训练的模型输出混乱，不一定是前向实现出错。

## 复习：先独立回答

1. 输入 token 数增加，而词表和 D 不变，哪几个轴应随之变化？
2. 要确认网络没有看未来，应比较什么而不是看生成文本是否合理？

<details><summary>展开核对要点</summary>

序列轴 N 及 Attention 的位置对轴变化，参数宽度和词表轴不因此改变。固定早期前缀、扰动未来输入，比较早期输出；还要关闭或控制随机因素并说明容差。

</details>

## 动手与达标证据

用已有 Attention 组件与小 FFN 拼装模型，写逐层 shape 和可见性测试，保存 CPU 配置和运行入口。未见训练结果不填写性能。
