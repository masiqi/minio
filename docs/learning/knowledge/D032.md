# D032｜语言模型数据：Label Shift、Packing 与 Mask

[目录](README.md) · [原教学卡](../daily/D031-D060-transformer-rag.md) · M03 · 前置：D007、D011、D024、D031

## 预习：问题与知识地图

语言模型训练依赖正确的输入与目标对应关系，而不只是把文本扔给网络。因果语言模型在位置 t 用已知前缀预测后面的 token；可见性、标签错位、无效目标和文档边界需要分别定义。

## 核心框架与例子

本次手工示例，完整 token 序列为 [A,B,C,EOS]：

| 输入位置内容 | 允许看到的内容 | 目标 |
| --- | --- | --- |
| A | A | B |
| B | A,B | C |
| C | A,B,C | EOS |

这是数据侧显式 shift 的教学表示。有些实现接收相同 input_ids/labels，在模型内部错位；不能在数据与模型两边重复 shift。Padding 的 Attention Mask 管“能读什么”，Loss Mask 管“哪些目标计分”。

Packing 将多段内容装入一个计算序列以减少浪费，但要明确文档分隔、跨文档可见性与边界目标的策略；简单拼接不是天然错误，也不是无须说明的默认真理。

## 易错边界

让位置 t 看到自己应预测的 t+1 内容会泄漏目标。按重叠 chunk 随机划分还可能泄漏文档。有效目标的聚合分母必须与 mask、权重和损失 API 一致。

## 复习：先独立回答

2. 训练 Loss 异常接近零但续写失败，为什么先查标签和可见性？

目标是 R。模型可能学会复制已经看见的答案，或标签发生错位；这类数据/目标错误不能靠扩大模型修复。
