# D025｜T07：从最终 Loss 回到所有 Head 与 W_O

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M02 · 前置：D013、D020、D023

## 预习：要回答的完整问题

通常是否先训练 Head，再训练 W_O？标准全参数端到端训练一般不这样分阶段：一次前向确定 Loss，反向沿整张计算图求梯度，优化器对受管理参数共同更新。但一次 step 只是一次调整，不是把所有参数训练完成。

## 核心框架与计算路径

前向：X → 各组 Q/K/V → 各 Head 输出 O_h → C=Concat(O_h) → Y=CW_O → 下游网络 → Loss。

反向：上游 G_Y → dW_O=CᵀG_Y、G_C=G_YW_Oᵀ → 按 Concat 区段分回 G_Oh → 加权 V/Softmax/QKᵀ → 各自 W_Qh、W_Kh、W_Vh。共享输入的梯度再汇总多头贡献。

本次示例：两个 Head 各输出 2 维，Concat 为 4 维。如果 G_C=[1,2,3,4]，回到两个 Head 的对应梯度分别是 [1,2] 与 [3,4]。Concat 没有参数，仍是需要传播梯度的运算。

## 易错边界

W_O/W_Q 等是跨样本共享的可学习参数；attention weights 是随输入计算出来的中间结果，不是同一类“权重”。冻结、断图、未交给优化器、数值零梯度要分别检查。不能保证每次所有参数都非零更新或验证效果必然提高。

## 复习：先独立回答

1. 最终只有一个 Loss，为什么每个 Head 的梯度还能不同？
2. Concat 没参数，为何不能把它视为反向链路的终点？

<details><summary>展开核对要点</summary>

不同路径包含不同中间值与局部导数，同一 Loss 的敏感度因此不同。Concat 只是重排/汇合信息，反向应将上游梯度对应分路，否则早期参数收不到信号。

</details>
