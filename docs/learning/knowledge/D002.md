# D002｜向量、矩阵与 batch/sequence/feature 轴

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M00 · 前置：[D001](D001.md)

## 预习：问题与知识地图

本单元解决“看到几个数字，却不知道它们在数什么”。标量是一个数；一个 token 的表示可以是一条 D 维向量；N 个 token 排成 N×D；B 条等长序列组成 B×N×D。这里 B 是样本数，N 是序列位置数，D 是每个位置的特征数。

## 核心框架与例子

本次教学例：X 的 shape 为 2×5×6，采用从 0 开始的下标。X[0] 是第一条序列，shape 5×6；X[0,2] 是其中第三个 token，shape 6；X[0,2,3] 是该 token 的第四个特征，是标量。

“某一行是一个 token”只适用于已经说明轴布局的 N×D 矩阵。N×N 的 Attention 矩阵里，两条轴都是位置；第二条轴不是表示维度。shape 相同也可能有不同含义，所以要同时写尺寸和轴名。

## 易错边界

100 个 64 维向量不是一个 6400 维 token。对这 100 个向量加权求和，只得到一个 64 维向量；为 100 个 Query 各做一次，才得到 100×64。

## 复习：先独立回答

1. B=3、N=4、D=7 时，X[1,2] 与 X[:,:,0] 的 shape 各是什么？
2. 将每条序列增加 2 个 token，与把每个 token 增加 2 个特征，分别改变哪里？

<details><summary>展开核对要点</summary>

X[1,2] 是 7 维；X[:,:,0] 是 3×4。增加位置后是 3×6×7；增加特征后是 3×4×9。两种变化解决的不是同一个问题。

</details>

## 动手与达标证据

先在纸上标轴，再写索引和 shape 断言。能给陌生 shape 的每条轴说出含义，而非只记住乘法结果。错在轴就回到一张 token×feature 数表，不重讲全部数学。
