# D045｜P2 需求、数据边界与评测集先行

## 预习：问题与知识地图

先定义回答成功，再搭 RAG。系统需要什么证据、哪些数据能用、什么时候该回答/拒答/澄清，比先选向量库更重要。离线 ingestion 建索引，在线 query 找证据并生成，两条链分别有版本与故障。

## 核心框架与案例

本次教学问题集含五类：原文直接事实、跨段关联、资料无答案、资料冲突、用户无权限。每例记录问题、允许数据范围、证据出处、预期行为及评价方式。无答案题的成功可能是准确说明缺证据，不是编出最流畅的答复。

原计划的20–40例是教学起点，不是充分统计样本。可以先覆盖重要失败类别，再随着真实失败扩充，保留未用于调参的评估部分。

问题无唯一答案时，应定义必须满足的证据与约束，而非要求文字与参考答案逐字相同。权限检查不能等到系统搭完才补。

## 易错边界

资料在网上能看到，不等于任何用途和外发都获授权。答案长度、语言流畅、检索返回很多片段都不是充分成功标准。只准备正例会漏掉无答案和越权行为。

## 复习：先独立回答

1. 为什么无答案和越权题必须进入起步评测？
2. 同一问题存在两种合理表述，怎样避免错误扣分？
