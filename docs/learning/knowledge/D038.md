# D038｜生成策略与随机性

[目录](README.md) · [原教学卡](../daily/D031-D060-transformer-rag.md) · M04 · 前置：D004、D035

## 预习：问题与知识地图

网络提供 logits，生成策略决定如何从候选中选择。需要分清 greedy、temperature、Top-K、Top-P 与停止条件，而不是把所有随机性都叫“创造力”。不同策略的比较要固定模型、输入、长度预算和其他设置。

## 核心框架与例子

Temperature 常以 logits/T 调整分布，T>0；较低温度通常更集中，较高温度更平缓，T=0 的接口语义由具体实现定义。Greedy 取最大分数，采样按分布抽取。

本次候选概率 [0.5,0.3,0.15,0.05]。Top-K=2 保留前两项；Top-P=0.8 在这个无边界实现差异的示例中保留累计达到 0.8 的前两项，重新归一化为 [0.625,0.375]。换成更平坦的分布，Top-P 的候选数量可能增加，而 Top-K 仍固定数量。

EOS、长度、取消是独立的停止条件，不要让无法生成 EOS 的教学模型无限运行。

## 易错边界

低温不消除幻觉；高温不证明回答有价值。同一个 seed 不能脱离设备、版本和执行条件承诺完全一致。截断之后的概率是在保留候选中重新定义的分布。
