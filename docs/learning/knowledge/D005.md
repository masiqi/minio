## 预习：问题与知识地图

目标不是背 API，而是让数学意图和代码里的轴一致。Tensor 的 shape 说明结构，dtype 说明数值类型，device 说明存放与计算设备。Parameter 是供模块管理的可学习参数对象；整数 token ID 是索引，不是同样被梯度优化的浮点权重。

## 核心框架与例子

本次示例：X=[[1,2,3],[4,5,6]]。转置得到 [[1,4],[2,5],[3,6]]；按原顺序 reshape 成 3×2 得到 [[1,2],[3,4],[5,6]]。shape 一样，元素对应关系不同。

matmul 做矩阵乘法；transpose/permute 改变轴顺序；reshape 重新解释元素布局；broadcast 按对齐规则扩展运算。对 B×N×D 的输入乘 D×F，输出 B×N×F，不要为了乘得上随意改 shape。带 bias 时应确认广播到哪个轴。

## 易错边界

“输出 shape 对了”并不能证明计算对。随机初始化不同不代表 bug。参数被注册、需要梯度、进入计算图、被优化器管理是不同检查项，完整训练在 M02 学。

## 复习：先独立回答

1. 为什么 reshape 成转置后的大小不能替代转置？
2. B×N×F 输出加一个长度 F 的 bias，与加长度 N 的向量，语义上有什么不同？

<details><summary>展开核对要点</summary>

前者不交换元素的轴身份。长度 F 的 bias 是按输出特征共享；长度 N 未必可广播，即使因尺寸巧合能运算，也可能把位置当特征。

</details>
