## 预习：问题与知识地图

最终只有一个 Loss，为什么前面许多参数都能得到更新信号？关键是中间量之间存在可微依赖。一条路径上乘局部导数；同一量经多条路径影响 Loss 时，各路径贡献相加。

## 核心框架与例子

本次计算图：u=ax，y_hat=bu，L=½(y_hat-y)²。取 x=2、a=1、b=3、y=8，得到 u=2、y_hat=6、L=2。

```text
dL/dy_hat = y_hat-y = -2
dL/db = (-2)×u = -4
dL/da = (-2)×b×x = -12
```

同一个最终误差，沿不同路径经过不同局部系数，因此梯度不同。所有梯度先按 a=1、b=3 这个快照求出，再更新；不能先改 b 后拿新 b 计算本轮 a 的梯度。

## 易错边界

反向传播不是把 Loss 平均分给参数。共享参数在多处使用，其梯度要汇总，而不是只看最近的一条路径。梯度非零只意味着本次局部敏感，不等于已经学会。
