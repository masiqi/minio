# D023｜T06A：分类、Logits、交叉熵

[目录](README.md) · [原教学卡](../daily/D001-D030-foundations-training.md) · M02 · 前置：D004、D021

## 预习：问题与知识地图

分类器给每个候选类别一个 logit，再用目标类别定义损失。Logit 是未归一化分数；Softmax 后才是候选分布；标签通常是目标类别 ID。Attention Softmax 在 Key 位置上分配信息，分类 Softmax 在类别上分配概率，轴的含义不同。

## 核心框架与例子

无标签平滑、无类别权重的单目标交叉熵：L=-log p_y。若目标概率是 0.5，L≈0.693；目标概率是 0.25，L≈1.386。即使最高分的类别没有变化，正确类别的概率变化仍会改变 Loss。

实际训练通常把 logits 直接交给数值稳定的 CrossEntropyLoss 实现，不先手动 Softmax 再当 logits 传入。对序列任务，先确定类别轴，再确定有效位置及聚合方式。本次简单 mean 约定：总有效目标损失除以有效目标数；加入类别权重后分母规则需查 API。

## 易错边界

最高概率不等于事实保证。目标 ID 不需要是一个 D 维语义向量。Padding 可被忽略，但必须确认忽略发生在哪里、分母如何计算；不能让大量 padding 稀释报告的损失。
