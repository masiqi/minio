## 2. 编号、工期与已有进度

M00–M10 是稳定的能力编号；D001–D090 是本次细化后的学习日单元；实际会话继续记录日期。历史 Day 1–5 不改名，也不要求学习者从 D001 排队重学。

仓库中若保留 L001 等其他粒度的学习日稿，与 D 计划按 M 模块和能力证据对齐，不把两套编号累加为两套必修。**本入口的 90 卡是本次“全部章节及每日计划提前准备”的细粒度执行版。** 历史稿保留，不据编号重新计一次完成度。

“学习日”不强制等于自然日。一般单元暂以 60–90 分钟作为排程假设，代码实验和回补可拆多次；用户每日稳定时长、设备与预算尚未确认。按 90 个完整单元计算，基础排程约 90–135 小时，未含额外环境排错和长实验；已有证据可抵扣。V2 总纲中的 80–106 小时属于更粗粒度初估，不应继续当作本细化版的完成上限。

30/60/90 个自然日是回顾窗口，不是自动掌握或强制毕业期限。首次排程目标可分别检查基础与训练闭环、可评测 RAG/Agent 初版、综合交付与答辩；实际抵达位置由时长、已有能力和验收结果决定。不能为压进 30 天而删去训练、数据、Evaluation 或安全。

## 4. 前置依赖：哪些必须先学，哪些只是推荐顺序

基础依赖链：M00 → M01 的表示/Attention；M00 → M02 的训练基础；M01+M02 → M03；M03 → M04 的底层推理解释。

应用依赖链：模型调用契约 → RAG 或 Agent；接入 Retrieval 工具才要求相应 RAG 能力。训练一个模型不是调用现成模型开发 Agent 的硬门槛，学习 RAG 也不是所有 Agent 的硬门槛。

本项目把底层基础前置，是针对当前学习者希望独立解释和排错的目标，而非把所有 AI 应用开发者都定义为必须从零预训练模型。Evaluation 和安全在 D015/D024 的数据划分、D045 的问题集、D053 的权限、D060 的审批就开始；M08 是深化而非首次出现。

## 6. 三条持续实践线与证据

**P1 微型 Transformer：** D014 形成 Attention 组件，D033–D035 完成模型、训练与生成，D036 验收；D039/D042 复用于 cache 和参数高效适配的最小实验。以正确性和机制为目标，不以流畅输出或 GPU 规模为成绩。

**P2 可评测 RAG / 阅读问答：** D045 先建问题集，D046–D053 建数据/检索/上下文/权限，D054–D056 评测与 LightRAG 对照，D057 验收。图方案不优于基线时，能依据证据决定不采用也是正确成果。

**P3 企业 Agent runtime：** D058–D067 实现 loop/工具/状态/恢复，D068–D073 接协议与执行边界，D074–D080 深化评测与可靠性，D081–D087 复用集成交付。不要求重造没有学习价值的基础设施。

每个项目都要有输入/数据授权、固定配置与版本、可运行入口、测试、失败案例与边界说明。mock 可验证控制流和故障处理，不能替代真实模型质量或真实性能实验；二者结果分开标记。

## 7. 从当前能力怎样进入，不清零也不假定都懂

已有 Baseline 和转录支持后端/企业工程优势，以及 Attention 主流程的复述证据；一般矩阵能力、Projection 信息损失、完整 MHA 独立实现与训练机制仍需分开验证。一个 (1×3)(3×2) 答案正确，不代表整套数学基础通过。

恢复学习先由教练核对状态与到期复习；针对 D003（投影/shape）、D008（表示）、D013（完整多头链）及必要代码能力只测未验证项。已稳定的 RNN 动机、已通过的流程不机械重问。记录抵扣后正式进入 D015–D026 的训练模块，再进入完整 block/LM。

当前不要求用户为了查看新方案先完成 Day 5，也不把“检查规划”的请求变成即时测验。

## 8. 教练的提前准备责任

开课前读当前 PLAN、LEARNING_STATE 和当天卡片，检查前置、所需公式、一个可算例子、一个反例、一个未见迁移题、可执行练习与验收。发现一整章依赖缺失，应在开课前修订路线，不等学生连续追问才临时补课。

临时问题分三类：本课必要的小澄清当场解释；已经属于后续完整模块的，指出具体 D/M 编号并保留问题；改变当前前置条件的，暂停依赖内容并调整计划。不能一律绕开，也不能把所有问题临时扩成新课。

“可以接受”“刚听懂”“紧接答案复述”只能作为理解线索。独立通过要求无提示解释、指定产物及一个改变条件的追问；延迟通过另做间隔验证。复习和表达贯穿，不是最后一周才开始。

## 9. 范围边界与后续扩展

本轮必须能独立实现/推导：基础张量与映射、Attention、微型模型训练循环、检索评测、工具/状态/恢复、权限/预算测试。

必须能解释并做选择：位置变体、KV cache/GQA、量化、SFT/LoRA/偏好优化、GraphRAG、MCP、Sandbox、框架边界。

多模态输入/文档解析在 D037/D046 处理应用契约与信息损失；从零训练视觉/语音/扩散模型、大规模分布式预训练、GPU kernel、自建虚拟化、完整强化学习算法证明不作为本轮必修。不是“不重要”，而是它们不应挤占当前角色目标下的共同基础和可交付能力；需要时另建带前置与验收的模块。
