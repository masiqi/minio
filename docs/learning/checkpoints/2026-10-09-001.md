## 4. 实验现场与可恢复证据

### RUN-01：单样本 Forward / Backward（用户已运行）

模型 prediction=x*w1+w2；loss=(prediction-y)**2。

x=2，y=10，w1=3，w2=1；两个参数设置 requires_grad=True，输入与标签当前不需要求梯度。一次 loss.backward() 后用户原输出：

```text
Prediction: 7.0
Loss: 9.0
w1 gradient: -12.0
w2 gradient: -6.0
```

该运行只算梯度，没有 step。之后用户手算 eta=0.1 得 (4.2,1.6)，该样本的解析 Loss=0；这次单样本更新没有单独贴运行输出，不能记为第二个实际 step 实验。

### RUN-02：两个样本的 Batch 平均梯度（用户已运行）

参数初始化 w1=4.2，w2=1.6；x=[2.0,3.0]，y=[10.0,13.0]。

prediction=x*w1+w2；loss_per_sample=(prediction-y)**2；loss=loss_per_sample.mean()；再 loss.backward()。

两个样本使用同一组标量参数。采用平方误差的算术平均，没有1/2系数、样本权重或正则项。用户原输出：

```text
Prediction: tensor([10.0000, 14.2000], grad_fn=<AddBackward0>)
Loss per sample: tensor([0.0000, 1.4400], grad_fn=<PowBackward0>)
Batch Loss: 0.7199997901916504
w1 gradient: 3.59999942779541
w2 gradient: 1.1999998092651367
```

解析值：A梯度=(0,0)，B误差=1.2、梯度=(7.2,2.4)；平均梯度=(3.6,1.2)。这些数字由用户主动推导，见 Q-04。

### RUN-03：同一个 Batch 的一次 SGD 参数更新（用户已运行）

沿 RUN-02 配置，optimizer=torch.optim.SGD([w1,w2],lr=0.1)，未启用 momentum/weight_decay。代码已执行梯度清零、Backward、step，并用新参数重新 Forward。用户原输出：

```text
Before: 4.199999809265137 1.600000023841858
After: 3.8399999141693115 1.4800000190734863
New Batch Loss: 0.3528001308441162
```

**最后已知数值断点：** w1≈3.84，w2≈1.48；训练数据仍为两样本 A=(2,10)、B=(3,13)。不代表用户进程仍在运行，重新启动脚本要明确初始化是(4.2,1.6)还是接续(3.84,1.48)，不能静默换配置。

教练对新参数作出的解析展开（不是用户单独打印的逐样本日志）：A预测9.16、误差-0.84、Loss0.7056；B预测13、Loss0；平均0.3528。用户独立判断了 A 会重新出现偏差、B 改善、Batch Loss下降。

RUN-02 的 .grad=(3.6,1.2) 对应更新前参数。step 后它不是自动变成新参数点的梯度；下一轮需按实验设计清零并重新 Forward/Backward。原代码中更新后的 new_loss 只计算/打印，没有显示第二次 backward/step 的证据。
